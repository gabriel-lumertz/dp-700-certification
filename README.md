# 📘 Treinamento DP-700 – Implementar Soluções de Engenharia de Dados com Microsoft Fabric

Este repositório contém conteúdo teórico desenvolvido ao longo do treinamento para a certificação **DP-700: Microsoft Fabric Data Engineer Associate**.

------

## 📑 Visão Geral do Treinamento

O curso fornece conhecimento de **nível intermediário** sobre a engenharia de dados no **Microsoft Fabric**. O conteúdo abrange:

- Ingestão e transformação de dados com Dataflows Gen2, pipelines e Apache Spark
- Implementação de **lakehouses**, tabelas Delta Lake e arquitetura de medalhão
- Inteligência em tempo real com Eventstream, Eventhouse, painéis em tempo real e Ativador
- Implementação, consulta, monitoramento e segurança de **data warehouses**
- Gerenciamento do ambiente: CI/CD, monitoramento e segurança de acesso aos dados

O conteúdo é estruturado para dar uma visão clara e prática do ecossistema Fabric, permitindo uma base sólida para a certificação.

------

## ✅ Objetivos de Aprendizagem

Ao final do treinamento, você será capaz de:

- Ingerir e orquestrar dados com **Dataflows Gen2**, **pipelines** e **Apache Spark**
- Implementar **lakehouses** com tabelas **Delta Lake** e a **arquitetura de medalhão**
- Processar dados em tempo real com **Eventstream**, **Eventhouse** e **Ativador**
- Implementar, consultar, monitorar e proteger um **data warehouse** no Fabric
- Gerenciar um ambiente Fabric com **CI/CD**, monitoramento e controles de acesso
