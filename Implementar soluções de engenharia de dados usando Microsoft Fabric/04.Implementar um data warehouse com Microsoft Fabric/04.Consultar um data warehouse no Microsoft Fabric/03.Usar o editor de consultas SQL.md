O editor de consultas SQL do Microsoft Fabric permite escrever e executar scripts T-SQL diretamente no seu data warehouse, com IntelliSense integrado e suporte à depuração.

## Iniciar um editor de consultas SQL

O editor de consultas SQL dá suporte a uma gama completa de operações T-SQL , desde consultar dados até criar tabelas, inserir linhas, conceder permissões e executar scripts complexos.

Para iniciar o editor de consultas SQL, selecione seu armazém no workspace onde ele está localizado. Ele se conecta automaticamente, sem exigir nenhuma informação de conexão.

No **Gerenciador** do warehouse, você pode criar uma nova consulta SQL das seguintes maneiras.

![Screenshot mostrando maneiras de criar uma nova consulta SQL em um data warehouse em Microsoft Fabric.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/3-sql-editor.png)

1. Menu **Página Inicial**: Selecione **Nova consulta SQL** ou selecione qualquer um dos modelos disponíveis.
2. **Nó de consultas** : selecione **...** à direita de **Minhas consultas** e selecione **Nova Consulta SQL**.

De qualquer forma, um novo item de consulta é criado automaticamente na pasta **Minhas consultas** no **Explorer** e salvo enquanto você trabalha.

## Executar consultas e exibir resultados

Para executar uma consulta, digite-a em um novo editor de consultas e selecione **Executar** na parte superior do editor.

![Screenshot do editor de consultas SQL no Microsoft Fabric mostrando uma consulta e o botão Executar.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/3-run.png)

A seção **Resultados** mostra uma pré-visualização, que será limitada a 10.000 linhas se exceder esse número.

## Trabalhar com os resultados da consulta

A barra de ferramentas de resultados oferece várias maneiras de explorar e exportar seus dados depois de executar uma consulta. Para acessar a maioria das opções, selecione primeiro uma instrução `SELECT` no editor.

![Captura de tela da barra de ferramentas de resultados do editor de consultas SQL mostrando os botões Abrir em Excel, Explorar esses dados, Visualizar resultados e Copiar.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/3-results-toolbar.png)

- **Open no Excel**: abre a consulta como uma conexão dinâmica em Microsoft Excel (não um download de arquivo estático). Depois que o arquivo for baixado, abra-o no Excel, selecione **Enable Editing** e, em seguida, **Enable Content**, aprove a caixa de diálogo Consulta de Banco de Dados Nativo e autentique com seu conta Microsoft. Seus dados são carregados como uma consulta conectada que você pode atualizar.
- **Explore esses dados (versão prévia)**: abre uma matriz lado a lado e uma exibição visual dos resultados para exploração ad hoc , útil para detectar tendências antes de criar um relatório de Power BI completo.
- **Visualizar resultados**: cria um visual Power BI diretamente dos resultados da consulta dentro do editor. Observação: não dá suporte a consultas com uma `ORDER BY` cláusula.
- **Cópia**: use o menu suspenso **Copiar** para copiar os resultados com os nomes das colunas, apenas os resultados ou apenas os nomes das colunas.
- **Vários conjuntos de resultados**: ao executar várias consultas, use a lista suspensa **Resultados** para navegar entre conjuntos de resultados individuais.

O editor de consultas também oferece a capacidade de salvar sua consulta realçada como uma exibição ou uma tabela, cada uma com recursos distintos:

- **Salvar como visualização**: Permite criar uma visualização no armazém de dados, usando a instrução SELECT destacada no editor de consultas.
- **Salvar como tabela**: Cria uma nova tabela com os resultados da consulta.

Para ambas as opções, você deve fornecer o esquema e o nome antes de confirmar a criação.

## Copilot no editor de consultas SQL

Se Copilot estiver habilitado em seu locatário, você verá **Fixar erros de consulta** e **Explain query** botões de ação rápida na faixa de opções do editor de consultas SQL, próximo ao botão **Run**.

![Captura de tela da faixa de opções do editor de consultas SQL, mostrando os botões de ação rápida do Copilot para Explicar consulta e Corrigir erros de consulta, além do painel de bate-papo do Copilot.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/3-copilot-quick-actions.png)

- **Explicar a consulta**: adiciona comentários de linguagem natural à consulta que descreve o que cada parte faz.
- **Corrigir erros de consulta**: detecta e corrige a sintaxe ou erros lógicos em sua consulta realçada. Esse botão fica esmaecido quando nenhum erro é detectado. Ele é ativado automaticamente quando o editor identifica um problema.

Você também pode abrir o painel de chat Copilot selecionando **Copilot** na barra de ferramentas, para gerar o T-SQL a partir de questões de linguagem natural.
