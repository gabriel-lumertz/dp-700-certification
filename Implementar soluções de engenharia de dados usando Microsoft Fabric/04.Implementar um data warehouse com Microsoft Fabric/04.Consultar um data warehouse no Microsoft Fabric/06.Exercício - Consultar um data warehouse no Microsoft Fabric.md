Agora é a sua chance de consultar dados em um data warehouse no Microsoft Fabric.

Neste exercício, você usará o editor de consultas SQL para consultar dados, verificar a consistência dos dados e salvar os resultados da consulta como uma exibição.

> [!Observação]
> 
> 
> Você precisa de acesso a uma capacidade paga ou de teste do Fabric para concluir este exercício. Para obter informações sobre a avaliação gratuita de Fabric, consulte [Fabric avaliação](https://aka.ms/fabrictrial).

Inicie o exercício e siga as instruções.
