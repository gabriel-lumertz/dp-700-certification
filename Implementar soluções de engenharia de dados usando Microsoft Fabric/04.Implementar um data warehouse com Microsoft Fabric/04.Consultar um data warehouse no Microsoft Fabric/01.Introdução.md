Microsoft Fabric Data Warehouse é uma plataforma completa para dados, análise e IA (Inteligência Artificial). Um data warehouse armazena, organiza e gerencia grandes volumes de dados estruturados e semiestruturados.

O data warehouse no Microsoft Fabric oferece um conjunto avançado de recursos que facilitam o gerenciamento e a análise de dados. Ele inclui recursos avançados de processamento de consulta e dá suporte aos recursos T-SQL transacionais completos de um data warehouse corporativo.

O processo de consulta de um data warehouse é um componente fundamental de business intelligence. Envolve extrair e analisar dados armazenados em um data warehouse, permitindo que os usuários descubram insights valiosos de grandes volumes de dados.

## Design do esquema em estrela

Em um data warehouse típico, os dados são organizados usando um esquema, geralmente um [esquema de estrela](https://learn.microsoft.com/pt-br/power-bi/guidance/star-schema) ou um [esquema de floco de neve](https://learn.microsoft.com/pt-br/power-bi/guidance/star-schema#snowflake-dimensions?azure-portal=true). O esquema de estrela e o esquema de floco de neve são abordagens de modelagem maduras amplamente adotadas por data warehouses relacionais. Essas abordagens exigem que você classifique tabelas como dimensão ou fato.

As tabelas de fatos armazenam os dados quantitativos mensuráveis sobre uma empresa, enquanto as tabelas de dimensão contêm atributos descritivos relacionados aos dados de fatos.

![Diagrama de um esquema em estrela para dados de vendas, com uma tabela de fatos central e cinco tabelas de dimensões que formam os pontos da estrela.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/1-star-schema.svg)

No diagrama, uma tabela de **fatos de Vendas** central armazena os dados mensuráveis – quantidades vendidas, receita e outros valores numéricos. As cinco tabelas de dimensão ao redor respondem às principais perguntas sobre cada venda: **Cliente** (quem), **Produto** (o quê), **Loja** (onde), **Data** (quando) e **Moeda** (quanto). Sem as tabelas de dimensão, os números da tabela de fatos não têm contexto.
