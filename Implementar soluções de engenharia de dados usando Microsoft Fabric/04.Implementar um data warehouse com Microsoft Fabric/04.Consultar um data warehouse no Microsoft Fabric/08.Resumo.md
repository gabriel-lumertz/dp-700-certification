Neste módulo, você explorou as ferramentas disponíveis para consultar um data warehouse no Microsoft Fabric. Você usou o editor de consultas SQL para gravar e executar consultas T-SQL, explorou o editor de consultas visuais como uma alternativa sem código e aprendeu a se conectar a um data warehouse de SQL Server Management Studio (SSMS) usando Microsoft Entra ID autenticação.

Cada ferramenta atende a uma necessidade diferente : o editor de consultas SQL oferece controle total sobre suas consultas, o editor de consultas visuais facilita a criação de consultas sem escrever código e ferramentas de cliente como o SSMS fornecem um ambiente familiar para profissionais de banco de dados.
