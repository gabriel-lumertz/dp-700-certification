SQL Server Management Studio (SSMS) é uma ferramenta gratuita para gerenciar e consultar bancos de dados baseados em SQL. Se você não o tiver instalado, poderá [baixar o SSMS](https://learn.microsoft.com/pt-br/sql/ssms/download-sql-server-management-studio-ssms). Você pode usá-lo para se conectar e consultar um data warehouse no Microsoft Fabric.

## Como conectar-se ao data warehouse

Siga estes passos para se conectar a um data warehouse no Fabric a partir do SSMS:

1.Navegue até seu workspace do Microsoft Fabric.

2.Selecione os três pontos **...** (reticências) à direita do nome do seu armazém e, em seguida, selecione **Copiar cadeia de caracteres de conexão SQL**.

![Captura de tela mostrando o menu Mais opções em um armazém com a opção Copiar cadeia de conexão SQL realçada.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/5-connection-string.png)

Uma caixa de diálogo é exibida mostrando a cadeia de conexão. Escolha **Copiar**.

![Captura de tela mostrando a caixa de diálogo Cadeia de caracteres de conexão SQL com um botão Copiar.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/5-connection-string-box.png)

3.Abra o SSMS. Na caixa de diálogo **Conectar ao Servidor**, cole a cadeia de conexão no campo **nome do servidor**.

4.No campo **Nome do Banco de Dados** , insira o nome exato do seu warehouse (por exemplo, `sample-dw`). Essa etapa é necessária: se o campo for deixado em branco, a conexão poderá falhar mesmo se a autenticação for bem-sucedida.

5.Na lista suspensa **Authentication**, selecione o método de autenticação de Microsoft Entra apropriado para sua organização e selecione **Connect**.

![Screenshot exibindo a guia Propriedades de Conexão do SSMS com nome do servidor, autenticação Microsoft Entra MFA e nome do banco de dados preenchidos.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/5-ssms-authentication.png)

6.Depois de estabelecer uma conexão, o SSMS mostra o armazém de dados conectado, juntamente com suas tabelas e visões correspondentes, todas prontas para consulta.

![Captura de tela mostrando o banco de dados sample-dw conectado no Explorador de Objetos do SSMS, com tabelas e visualizações visíveis.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/5-ssms-warehouse.png)

## Opções de autenticação

Microsoft Fabric dá suporte apenas à autenticação Microsoft Entra ID — a autenticação SQL não tem suporte. No menu suspenso **Autenticação**, selecione a opção Microsoft Entra adequada para a sua organização.

Para obter mais informações, consulte [Conectar ao servidor (página de logon) – Mecanismo de Banco de Dados](https://learn.microsoft.com/pt-br/ssms/f1-help/connect-to-server-login-page-database-engine) e [autenticação do Microsoft Entra como alternativa à autenticação SQL no Microsoft Fabric](https://learn.microsoft.com/pt-br/fabric/data-warehouse/entra-id-authentication).

## Outras ferramentas

Qualquer ferramenta de terceiros pode usar a cadeia de conexão SQL por meio de drivers ODBC ou OLE DB para se conectar a um Microsoft Fabric Warehouse ou a um endpoint de análise do SQL, utilizando a autenticação do Microsoft Entra ID.

> [!Observação]
> 
> 
> A porta TCP **1433** deve estar aberta no firewall de rede. Para obter mais informações, consulte [Conectividade do Warehouse](https://learn.microsoft.com/pt-br/fabric/data-warehouse/connectivity).
