O editor de consultas visuais no Microsoft Fabric fornece uma interface intuitiva, gráfica e sem código para a criação de consultas.

Para abrir o editor de consultas visuais, selecione a seta suspensa em **Nova consulta SQL** na barra de ferramentas e depois selecione **Nova consulta visual**.

- **Interface gráfica**: arraste e solte tabelas em uma tela para projetar visualmente suas consultas. O editor mostra as relações entre tabelas, tornando a estrutura de consulta fácil de entender rapidamente.

- **Geração automática de consulta**: ao projetar sua consulta, o T-SQL correspondente é gerado automaticamente, para que você possa se concentrar na lógica em vez da sintaxe.

## Criar sua consulta visualmente

Para criar uma consulta, arraste tabelas do **Explorer** para a tela.

![Captura de tela mostrando a opção Nova consulta visual selecionada no menu suspenso, com setas vermelhas indicando como arrastar as tabelas Data e Viagem do Explorer para a tela em branco.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/4-new-visual-query.png)

Depois que suas tabelas estiverem na tela, você poderá juntá-las clique em uma tabela com o botão direito do mouse e selecione **Mesclar consultas**.

![Captura de tela da tela do editor de consultas visuais com duas tabelas e a opção Mesclar consultas realçada no menu de contexto.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/4-merge-queries.png)

Na caixa de diálogo Mesclar, selecione a coluna de chave comum em cada tabela e escolha um tipo de junção e selecione **OK**.

![Captura de tela da caixa de diálogo Mesclagem no editor de consultas visuais mostrando opções de seleção de coluna e tipo de junção.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/4-merge-dialog.png)

Depois de configurar sua consulta, selecione **Executar** para ver os resultados no painel abaixo da tela.

![Screenshot do editor de consultas visuais mostrando duas tabelas unidas na tela com os resultados da consulta exibidos no painel abaixo, incluindo Salvar como tabela, Baixar Excel arquivo e visualizar opções de resultados.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/query-data-warehouse-microsoft-fabric/media/4-visual-canvas.png)

Assim como o editor de consultas SQL, o editor de consultas visuais também fornece **Salvar como tabela** e **Salvar como exibição** na barra de ferramentas de resultados. Você também pode selecionar **Baixar arquivo Excel** para exportar resultados ou **Visualizar resultados** para criar um gráfico.

## Exibir o SQL gerado

À medida que você cria sua consulta visual, o T-SQL correspondente é gerado automaticamente. Selecione **Exibir SQL** na faixa de opções para inspecioná-lo ou **Editar script SQL** para abri-lo no editor de consultas SQL para edição adicional.

Para saber mais sobre o editor de consultas visuais, consulte [Consulta usando o editor de consultas visuais](https://learn.microsoft.com/pt-br/fabric/data-warehouse/visual-query-editor).
