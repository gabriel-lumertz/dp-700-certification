Agora é sua chance de proteger um warehouse no Microsoft Fabric.

Neste exercício, você aprenderá a proteger um warehouse usando os conceitos explorados neste módulo.

> [!NOTE]
> 
> 
> - Você precisa de uma licença de avaliação do Microsoft Fabric com a versão prévia do Fabric habilitada no locatário. Consulte [**Introdução ao Fabric**](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial) para habilitar sua licença de avaliação do Fabric.
> - Este exercício inclui etapas opcionais que exigem uma segunda conta de usuário para visualizar as medidas de segurança aplicadas. Se não for possível criar uma segunda conta, você ainda poderá concluir o exercício usando uma conta própria. Nesse caso, consulte as capturas de tela apresentadas no final de cada seção para ver os resultados esperados.

## **Como criar um segundo usuário para este exercício**

**Se você faz parte de uma organização que tem um locatário do Entra ou do Microsoft 365:**

Trabalhe com o administrador de identidade para criar o segundo usuário no [**Entra**](https://entra.microsoft.com/) ou no [**Centro de administração do Microsoft 365**](https://admin.cloud.microsoft/).

**Se você _não_ for membro de uma organização com um locatário do Entra ou do Microsoft 365:**

1. Não é possível criar uma conta de avaliação do Fabric com seu email pessoal. Você pode se inscrever para uma [**avaliação do Microsoft 365**](https://learn.microsoft.com/pt-br/power-bi/enterprise/service-admin-signing-up-for-power-bi-with-a-new-office-365-trial). Um novo tenant organizacional será criado, e você se tornará o administrador de Usuário e Cobrança do tenant. Então, poderá criar usuários.
2. Criar o segundo usuário no [**centro de administração do Microsoft 365**](https://admin.cloud.microsoft/#/users?azure-portal=true) Veja: [**Adicionar usuários**](https://learn.microsoft.com/pt-br/microsoft-365/admin/add-users/add-users)
3. Habilite a avaliação do Fabric usando [**Introdução ao Fabric**](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial).

Inicie o exercício e siga as instruções.
