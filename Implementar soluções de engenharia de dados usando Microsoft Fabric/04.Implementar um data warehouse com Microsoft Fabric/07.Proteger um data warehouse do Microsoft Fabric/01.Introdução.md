O [Microsoft Fabric Data Warehouse](https://learn.microsoft.com/pt-br/fabric/data-warehouse/) é uma plataforma completa para dados, análise e IA (Inteligência Artificial). Refere-se ao processo de armazenar, organizar e gerenciar grandes volumes de dados estruturados e semiestruturados.

Em um warehouse, os administradores têm acesso a um conjunto de tecnologias destinadas a proteger as informações confidenciais. Essas medidas de segurança têm a capacidade de proteger ou mascarar dados de usuários ou funções sem a autorização adequada, garantindo a proteção de dados nos pontos de extremidade de análise do warehouse e do SQL. Isso garante uma experiência de usuário tranquila e segura, sem a necessidade de alterações nos aplicativos existentes.

## Noções básicas sobre os recursos de segurança

Os engenheiros de dados que costumam ser bem versados no mecanismo SQL e adeptos ao uso do T-SQL acharão os warehouses do Microsoft Fabric fáceis de usar.

Isso ocorre porque os warehouses são ativados pelo mesmo mecanismo SQL com o qual os engenheiros estão familiarizados, permitindo que realizem consultas complexas e manipulações de dados. A ampla gama de recursos de segurança do mecanismo SQL permite ainda um mecanismo de segurança sofisticado no nível do warehouse.

- [**Funções de espaços de trabalho**](https://learn.microsoft.com/pt-br/fabric/data-warehouse/workspace-roles/) – projetadas para fornecer diferentes níveis de acesso e controle dentro do espaço de trabalho. Você pode atribuir usuários às várias funções de workspace, como **Administrador**, **Membro**, **Colaborador** e **Visualizador**. Essas funções são cruciais para manter a segurança e a eficiência das operações de armazenamento de dados em uma organização.

- [**Permissões de item**](https://learn.microsoft.com/pt-br/fabric/data-warehouse/share-warehouse-manage-permissions/) – os armazéns individuais podem ter permissões de item atribuídas diretamente a eles. A principal intenção por trás da atribuição dessas permissões é facilitar o compartilhamento do warehouse para uso downstream.

- [**Segurança de proteção**](https://learn.microsoft.com/pt-br/fabric/data-warehouse/security#granular-security?azure-portal=true) de dados – para um controle mais preciso, você pode usar o T-SQL para conceder permissões específicas aos usuários. O warehouse dá suporte a uma variedade de recursos de proteção de dados que permitem que os administradores protejam dados confidenciais contra o acesso não autorizado. Isso inclui a segurança em nível de objeto para objetos de banco de dados, a segurança em nível de coluna para colunas de tabela, a segurança em nível de linha para linhas de tabela usando filtros de cláusula `WHERE` e a Máscara Dinâmica de Dados para ocultar dados confidenciais, como endereços de email. Esses recursos garantem a proteção de dados entre warehouses e pontos de extremidade de análise de SQL sem exigir alterações nos aplicativos.
