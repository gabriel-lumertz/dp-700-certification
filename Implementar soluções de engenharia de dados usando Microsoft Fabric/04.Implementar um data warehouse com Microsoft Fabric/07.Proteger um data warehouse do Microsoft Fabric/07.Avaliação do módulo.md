1.Qual é a principal vantagem da DDM (Máscara de Dados Dinâmicos)?

> [!Correct]
> Ela limita a exposição de dados, ocultando as informações confidenciais em tempo real.

Ela altera os dados reais no banco de dados.

É necessário uma codificação complexa para implementá-la.

2.Qual é a finalidade de uma função de predicado de segurança na RLS (Segurança em Nível de Linha)?

> [!Correct]
> Ela determina se uma linha é acessível a um usuário de acordo com determinadas condições.

Ela permite conversões de tipo em funções de predicado.

Ela permite que os usuários executem consultas ad hoc.

3.O que acontece quando um usuário recebe uma permissão e, em seguida, nega a mesma permissão em um warehouse?

A instrução GRANT substitui DENY e o usuário terá acesso ao objeto específico.

> [!Correct]
> DENY sempre substitui GRANT e o usuário tem acesso negado ao objeto específico.

O usuário tem as duas permissões e isso causa um conflito.
