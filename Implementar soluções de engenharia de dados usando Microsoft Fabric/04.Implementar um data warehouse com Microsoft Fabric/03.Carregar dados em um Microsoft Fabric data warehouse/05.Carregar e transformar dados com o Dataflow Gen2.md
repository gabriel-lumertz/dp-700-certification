[O Dataflow Gen2](https://learn.microsoft.com/pt-br/fabric/data-factory/dataflows-gen2-overview) é a nova geração de fluxos de dados. Ele fornece uma experiência abrangente do Power Query, orientando você em cada etapa de importação de dados para seu fluxo de dados. O processo de criação de fluxos de dados foi simplificado, reduzindo o número de etapas envolvidas.

Use fluxos de dados em pipelines de dados para ingerir dados em um lakehouse ou warehouse, ou para definir um conjunto de dados para um relatório do Power BI.

## Criação de um fluxo de dados

Para criar um novo fluxo de dados, navegue até o workspace e selecione **+ Novo**. Se o **Dataflow Gen2** não estiver visível na lista, selecione **Mais opções** e, em seguida, localize **o Dataflow Gen2** na seção **Data Factory** .

![GIF animado mostrando como iniciar o Dataflow Gen2 a partir da área de trabalho.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/5-load-using-dataflow.gif)

## Importar dados

Depois que o Dataflow Gen2 é iniciado, há muitas opções para carregar seus dados disponíveis.

![Captura de tela mostrando como iniciar um pipeline de dados do ativo do warehouse.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/5-import-options.png)

Você pode carregar diferentes tipos de arquivo com apenas algumas etapas. Por exemplo, para carregar um texto ou arquivo CSV do computador local.

![Captura de tela mostrando como carregar um texto ou arquivo CSV.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/5-load-file.png)

Depois que os dados são importados, você pode começar a criar seu fluxo de dados, você pode decidir limpar seus dados, remodelar, remover colunas e criar novos. Todas as etapas que você executa são salvas.

## Transformar dados com Copilot

O Copilot pode ser uma ferramenta valiosa para ajudar com transformações de fluxo de dados. Digamos que temos uma coluna _gender_ que contém _"Masculino"_ e _"Feminino"_ e queremos transformá-la.

A primeira etapa é ativar o Copilot em seu fluxo de dados. Depois que isso for feito, você poderá fornecer instruções específicas sobre a transformação que deseja executar.

Por exemplo, você pode inserir o seguinte comando: _"Transformar a coluna Gênero. Se Masculino 0, se Feminino 1. Em seguida, converta em inteiro."_

![Captura de tela mostrando como usar Copilot para aplicar a transformação em um fluxo de dados.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/5-copilot.png)

O Copilot adiciona uma nova etapa automaticamente e você sempre pode revertê-la, se desejar, ou continuar a compilá-la para novas transformações.

## Adicionar um destino de dados

Com o recurso **Adicionar destino de dados** , você pode separar sua lógica ETL e o armazenamento de destino. Essa separação pode levar a um código mais limpo e mais mantenedível e pode facilitar a modificação do processo ETL ou da configuração de armazenamento sem afetar o outro.

Depois que os dados são transformados, a próxima etapa é adicionar uma etapa de destino. Na guia **Configurações de Consulta** , selecione **+** para adicionar uma etapa de destino ao fluxo de dados.

![Captura de tela mostrando a opção de adicionar um destino de dados em um fluxo de dados.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/5-add-destination.png)

As opções de destino a seguir estão disponíveis.

- Banco de Dados SQL do Azure
- Lakehouse
- Azure Data Explorer (Kusto)
- Azure Synapse Analytics (SQL DW)
- Armazém

Os dados carregados em um destino como um armazém podem ser facilmente acessados e analisados usando várias ferramentas. Isso melhora a acessibilidade de seus dados e permite uma análise de dados mais flexível e abrangente.

Ao selecionar um warehouse como destino, você pode escolher os métodos de atualização a seguir.

![Diagrama mostrando visualmente a diferença entre o acréscimo e os métodos de substituição para atualizar uma linha.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/5-update-table-options.png)

- **Acrescentar:** Adicione novas linhas a uma tabela existente.
- **Substituir:** Substitua todo o conteúdo de uma tabela por um novo conjunto de dados.

## Publicar um fluxo de dados

Depois de escolher o método de atualização, a etapa final é publicar seu fluxo de dados.

A publicação torna suas transformações e operações de carregamento de dados ativas, permitindo que o fluxo de dados seja executado manualmente ou em um cronograma. Esse processo encapsula suas operações de ETL em uma única unidade reutilizável, simplificando seu fluxo de trabalho de gerenciamento de dados.

Todas as alterações feitas no fluxo de dados entrarão em vigor quando forem publicadas. Portanto, sempre certifique-se de publicar seu fluxo de dados depois de fazer modificações relevantes.
