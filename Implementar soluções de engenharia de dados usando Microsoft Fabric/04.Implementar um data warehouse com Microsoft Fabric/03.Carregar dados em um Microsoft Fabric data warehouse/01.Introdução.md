[Microsoft Fabric Data Warehouse](https://learn.microsoft.com/pt-br/fabric/data-warehouse/) é uma plataforma completa para dados, análise e IA (Inteligência Artificial). Refere-se ao processo de armazenar, organizar e gerenciar grandes volumes de dados estruturados e semiestruturados.

O data warehouse no Microsoft Fabric oferece um conjunto avançado de recursos que facilitam o gerenciamento e a análise de dados. Ele inclui capacidades avançadas de processamento de consultas e dá suporte para todas as funcionalidades transacionais do T-SQL, como um data warehouse empresarial.

Ao contrário de um pool de SQL dedicado no Synapse Analytics, um warehouse do Microsoft Fabric é centralizado em um único data lake. Os dados no Microsoft Fabric warehouse são armazenados no formato de arquivo Parquet. Essa configuração permite que os usuários foquem em tarefas como preparação de dados, análise e relatórios. Ele aproveita as extensas funcionalidades do mecanismo SQL, em que uma cópia exclusiva de seus dados é armazenada no [Microsoft OneLake](https://learn.microsoft.com/pt-br/fabric/onelake/onelake-overview).

## Entenda o processo de ETL (Extração, Transformação e Carregamento)

A ETL fornece a base para as atividades de análise de dados e de data warehouse. Vamos examinar alguns aspectos da manipulação de dados em um processo de ETL.

|Descrição|
|---|---|
|Extração de dados|Envolve conectar-se ao sistema de origem e coletar os dados necessários para o processamento analítico.|
|Transformação de dados|Envolve uma série de etapas executadas nos dados extraídos para convertê-los em um formato padrão. Combinar dados de diferentes tabelas, limpeza de dados, eliminação da duplicação de dados e realização de validações de dados.|
|Carregamento de dados|Os dados extraídos e transformados são carregados nas tabelas de fatos e dimensões. Para uma carga incremental, isso envolve a aplicação periódica de alterações contínuas de acordo com o requisito. Esse processo geralmente envolve a reformatação dos dados para garantir sua qualidade e compatibilidade com o esquema do data warehouse.|
|Otimizações pós-carregamento|Após os dados serem carregados, certas otimizações podem ser realizadas para melhorar o desempenho do data warehouse.|

Todas essas etapas do processo de ETL podem ser executadas em paralelo, dependendo do cenário. Assim que alguns dados estiverem prontos, eles serão carregados sem esperar que as etapas anteriores sejam concluídas.

Nas próximas unidades, exploraremos várias formas de carregar dados em um data warehouse e como elas podem facilitar as tarefas de criação de uma carga de trabalho de data warehouse.
