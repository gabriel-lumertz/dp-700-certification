Não há uma solução única para carregar dados. A melhor abordagem depende das especificidades de seu requisito de negócios e da pergunta que você está tentando responder.

Quando se trata de carregar dados em um data warehouse, há várias considerações a serem consideradas.

|Descrição|
|---|---|
|Volume de carga & frequência|Avalie o volume de dados e a frequência de carga para otimizar o desempenho.|
|Governança|Todos os dados que chegam ao OneLake são regidos por padrão.|
|Mapeamento de dados|Gerenciar o mapeamento da origem para o processo de preparo e para o warehouse.|
|Dependências|Entenda as dependências no modelo de dados para carregar dimensões.|
|Design de script|Crie scripts de importação eficientes considerando nomes de coluna, regras de filtragem, mapeamento de valor e indexação de banco de dados.|
