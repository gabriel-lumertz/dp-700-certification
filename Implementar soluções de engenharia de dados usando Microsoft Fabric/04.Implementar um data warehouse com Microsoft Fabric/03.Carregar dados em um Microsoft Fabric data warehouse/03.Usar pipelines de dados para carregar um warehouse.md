O Warehouse do Microsoft Fabric fornece ferramentas integradas de ingestão de dados, permitindo que os usuários carreguem e ingiram dados em warehouses em grande escala por meio de experiências de codificação ou não codificação.

O pipeline de dados é o serviço baseado em nuvem para integração de dados, que habilita a criação de fluxos de trabalho para movimentação de dados e transformação de dados em escala. É possível criar e agendar pipelines de dados que podem ingerir e carregar dados de armazenamentos de dados diferentes. Você pode criar processos complexos de ETL ou ELT que transformam os dados visualmente com fluxos de dados.

A maior parte da funcionalidade dos pipelines de dados no Microsoft Fabric vem do Azure Data Factory, permitindo a integração e a utilização perfeitas de seus recursos no ecossistema do Microsoft Fabric.

> [!Observação]
> 
> 
> Todos os dados em um Data Warehouse são automaticamente armazenados no formato Delta Parquet no OneLake.

## Criar um pipeline de dados

Existem algumas maneiras de iniciar o editor do pipeline de dados.

- **No espaço de trabalho:** Selecione **+ Novo** e, em seguida, selecione **Pipeline de Dados**. Se não estiver visível na lista, selecione **Mais opções** e encontre **Pipeline de dados** na seção **Obter dados**.
    
- **No ativo do warehouse -** Selecione **Obter Dados** e, em seguida, **Novo pipeline de dados**.
    
    ![Captura de tela mostrando os atalhos para alguns recursos no ativo do warehouse.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/3-create-data-pipeline.png)
    

Existem três opções disponíveis ao criar um pipeline.

![Captura de tela mostrando as opções disponíveis ao criar um pipeline.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/3-build-pipeline.png)

|Opção|Descrição|
|---|---|
|**1. Adicionar a atividade de pipeline**|Inicia o editor de pipeline, no qual você poderá criar seu próprio pipeline.|
|**2. Cópia de dados**|Inicia um assistente para copiar dados de várias origens de dados para um destino de dados. Uma nova atividade de pipeline é gerada no final com uma tarefa de **Cópia de Dados** pré-configurada.|
|**3. Escolha uma tarefa para iniciar**|É possível escolher entre uma coleção de modelos predefinidos para ajudar a iniciar pipelines com base em muitos cenários.|

## Configurar o assistente de cópia de dados

O assistente de cópia de dados fornece uma interface passo a passo que facilita a configuração de uma tarefa de **Cópia de Dados**.

![Captura de tela que mostra o assistente para copiar dados.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/3-copy-data-assistant.png)

- **Escolha a fonte de dados:** Selecione um conector e forneça as informações de conexão.
- **Conectar-se a uma fonte de dados:** Selecione, pré-visualize e escolha os dados. Isso pode ser feito a partir de tabelas ou exibições, ou você pode personalizar sua seleção fornecendo sua própria consulta.
- **Escolha o destino dos dados:** Selecione o armazenamento de dados como destino.
- **Conectar-se ao destino dos dados:** Selecione e mapeie colunas da origem para o destino. Você pode carregar em uma tabela nova ou existente.
- **Configurações:** Defina outras configurações, como processo de preparo e valores padrão.

Após copiar os dados, você pode usar outras tarefas para transformá-los e analisá-los ainda mais. Também é possível usar a tarefa **Cópia de Dados** para publicar os resultados da transformação e da análise para business intelligence (BI) e consumo de aplicativos.

## Agendar um pipeline de dados

Você pode agendar seu pipeline de dados selecionando **Agendar** no editor de pipeline de dados.

![Captura de tela mostrando onde agendar um pipeline de dados no Designer de Pipeline.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/3-schedule-data-pipeline.png)

Também é possível configurar o agendamento selecionando **Configurações** no menu **Página Inicial** do editor de pipeline de dados.

![Captura de tela mostrando as propriedades de configuração ao agendar um pipeline de dados.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/load-data-into-microsoft-fabric-data-warehouse/media/3-schedule-configuration.png)

Recomendamos os pipelines de dados para uma experiência sem código ou de baixo código devido à interface gráfica do usuário. Eles são ideais para fluxos de trabalho de dados que são executados de forma agendada ou que se conectam a diferentes fontes de dados.

Para obter mais informações sobre pipelines de dados, consulte [Ingerir de dados em seu Warehouse usando pipelines de dados](https://learn.microsoft.com/pt-br/fabric/data-warehouse/ingest-data-pipelines).
