O Copilot no Data Warehouse do Microsoft Fabric fornece duas ações rápidas de IA: **Explicar** e **corrigir**. Essas ações ajudam você a escrever, entender e depurar consultas SQL com mais eficiência. Localizadas na parte superior do editor de consultas SQL, perto do botão **Executar** , essas ações rápidas aceleram a produtividade simplificando tarefas complexas.

- **Explicar**: adiciona um resumo na parte superior da consulta e comentários embutidos em toda a consulta para descrever sua funcionalidade. Antes de selecionar **Explicar**, realce a consulta ou a parte que você deseja que o Copilot explique: você pode selecionar a consulta inteira ou apenas uma seção.
- **Correção**: resolve automaticamente a sintaxe ou erros lógicos em sua consulta, usando a mensagem de erro SQL como contexto. O botão **Corrigir** só é habilitado depois que você executa uma consulta que retorna um erro — o Copilot usa automaticamente essa mensagem de erro como contexto, portanto, nenhuma entrada extra é necessária.

O Copilot usa o esquema do warehouse, o conteúdo da guia de consulta e os resultados de execução para fornecer comentários relevantes.

## Example

Com o seu armazém de exemplo aberto, expanda as vistas e selecione a vista **vw_PaymentAnalysis**. Selecione os três pontos ao lado da visualização e selecione **Nova Consulta SQL**>**CREATE**. Isso abrirá uma nova guia com o T-SQL na exibição.

[![Captura de tela das Ações Rápidas do Fabric Data Warehouse Copilot.](https://learn.microsoft.com/pt-br/training/wwl/get-started-copilot-fabric-data-warehouse/media/quick-actions.png)](https://learn.microsoft.com/pt-br/training/wwl/get-started-copilot-fabric-data-warehouse/media/quick-actions.png#lightbox)

Para usar **Explicar**, primeiro realce a consulta ou a parte que você deseja explicar e, em seguida, selecione o botão **Explicar** . O Copilot analisa sua consulta e gera comentários embutidos que explicam o que seu código faz. Se aplicável, Copilot também deixa um resumo na parte superior da consulta. Os comentários aparecem ao lado das linhas de código relevantes no editor de consultas. Você pode editar ou excluir os comentários conforme necessário.

SQL

```
-- Create a view named vw_PaymentAnalysis to analyze payment data
CREATE VIEW [dbo].[vw_PaymentAnalysis] AS
SELECT
    -- Select the type of payment from the Trip table
    PaymentType,
    -- Count the number of payments for each payment type
    COUNT(T.PaymentType) AS PaymentsCount,
    -- Sum the total amount processed for each payment type
    SUM(TotalAmount) AS TotalAmountProcessed
FROM 
    dbo.Trip AS T
-- Join the Trip table with the Date table on the DateID column
JOIN 
    dbo.[Date] AS D
    ON T.[DateID] = D.[DateID]
-- Filter the results to include only records from the year 2013
WHERE 
    YEAR(D.[Date]) = 2013
-- Group the results by PaymentType to aggregate the counts and sums
GROUP BY    
    PaymentType
```

## Resumo

As ações **rápidas Explicar** e **Corrigir** no Copilot são ferramentas avançadas para simplificar o desenvolvimento e a depuração de consultas SQL. Usando esses recursos, você pode melhorar sua produtividade e obter insights mais profundos sobre suas consultas.
