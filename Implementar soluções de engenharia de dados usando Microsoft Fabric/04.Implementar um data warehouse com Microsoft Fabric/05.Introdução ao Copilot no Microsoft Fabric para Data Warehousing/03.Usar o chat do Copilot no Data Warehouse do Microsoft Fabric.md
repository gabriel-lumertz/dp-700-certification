O painel de chat do Copilot no Data Warehouse do Microsoft Fabric permite que os usuários interajam com o Copilot usando linguagem natural. Este recurso permite que você faça perguntas sobre o seu data warehouse ou sobre conceitos gerais de armazenamento de dados. O Copilot pode gerar consultas SQL, fornecer explicações e até mesmo corrigir erros em suas consultas.

## Principais recursos

O painel de chat do Copilot oferece vários recursos. Ele pode converter prompts de linguagem natural em consultas T-SQL para dar suporte à geração de consultas. Você pode fazer perguntas sobre conceitos de data warehousing e receber respostas. Além disso, o Copilot fornece explicações de linguagem natural para código T-SQL para ajudar os usuários a entender as consultas. Ele também ajuda a resolver erros T-SQL oferecendo sugestões para corrigir problemas.

## Como começar

1.**Abrir um Data Warehouse**: Navegue até a seção de rotinas do Data Warehouse e abra um armazém.
2.**Abra uma nova consulta SQL**: inicie uma nova consulta SQL.
3.**Acesse o Painel de Chat do Copilot**:
- Selecione o botão **Copilot** na faixa de opções para abrir o painel de chat.
- O painel de chat fornece prompts de início para ajudá-lo a se familiarizar com o Copilot.
4.Insira o seguinte prompt:

Prompt do Copilot

```
How can I import data into my Fabric Warehouse?
```

## Casos de uso avançados com comandos

Para executar tarefas específicas, use os seguintes `/` comandos no início da mensagem de chat:

|Command|Description|
|---|---|
|`/generate-sql`|Gere uma consulta SQL do prompt fornecido.|
|`/explain`|Forneça uma explicação para a consulta na guia consulta ativa.|
|`/fix`|Corrija erros na consulta na guia consulta ativa. Opcionalmente, adicione contexto.|
|`/question`|Gere uma resposta de linguagem natural para o prompt.|
|`/help`|Acesse a documentação e as diretrizes para usar o Copilot.|

### Exemplos

Para `/generate-sql`, `/question`e opcionalmente `/fix`, incluir informações adicionais sobre sua intenção. Por exemplo:

- `/generate-sql select numbers 1 through 10`
- `/question what types of security are supported for this warehouse?`
- `/fix using CTAS instead of ALTER TABLE`

## Contexto e histórico da conversa

O painel do Copilot Chat mantém o contexto entre prompts na mesma sessão. Isso significa que as mensagens de acompanhamento podem fazer referência a consultas anteriores, por exemplo, você pode gerar uma consulta com um prompt e refiná-la com um acompanhamento como `/fix using CTAS instead of ALTER TABLE` sem repetir o contexto completo. Essa interação de vários turnos melhora a precisão de resposta do Copilot e torna o desenvolvimento de consultas iterativas mais rápido.

## Resumo

O painel de chat do Copilot no Data Warehouse do Fabric pode gerar consultas SQL, ajudar a corrigir erros e dar suporte ao aprendizado sobre data warehousing. Usando o idioma natural e os comandos disponíveis, você pode executar tarefas comuns de uma interface.
