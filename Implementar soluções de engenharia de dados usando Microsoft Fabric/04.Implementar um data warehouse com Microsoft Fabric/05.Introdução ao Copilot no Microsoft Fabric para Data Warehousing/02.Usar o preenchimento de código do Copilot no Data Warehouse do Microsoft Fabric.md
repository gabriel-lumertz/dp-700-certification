O Copilot no Fabric for Data Warehouse fornece sugestões de código T-SQL baseadas em contexto diretamente no editor de consultas. Ele usa o esquema e o contexto de consulta do warehouse para oferecer conclusões embutidas, desde o término de uma linha até a geração de blocos de código maiores. Ele pode ajudá-lo a escrever SQL, reduzir a digitação repetitiva e detectar alguns erros. Independentemente de você ser novo no SQL ou experiente, o Copilot pode ajudar com o código de rotina para que você possa se concentrar nas tarefas de design e otimização.

## Pré-requisitos

Para começar, verifique se o administrador habilitou a opção de locatário do Copilot e se sua capacidade está em uma região com suporte. SKUs pagos (F2 ou superior ou um SKU P) são necessários, pois SKUs de avaliação não são compatíveis. Se as configurações de locatário restringirem o processamento de dados a regiões geográficas específicas, confirme se as permissões necessárias estão habilitadas.

Em seguida, verifique se você tem um armazém criado em seu workspace do Fabric. Neste módulo de aprendizado, usaremos o [**armazém de exemplo**](https://learn.microsoft.com/pt-br/fabric/data-warehouse/create-warehouse-sample) fornecido pela Microsoft.

## Como usar a conclusão de código do Copilot

Antes de começar, verifique se a configuração **Mostrar Conclusões do Copilot** está habilitada. Em **configurações** do seu warehouse, selecione o painel **Copilot** e confirme se a opção está ativada. Você também pode verificar a barra de status na parte inferior do editor de consultas: ela mostra de relance se as conclusões estão ativas.

Com o preenchimento habilitado, comece a digitar sua consulta no editor de SQL, e o Copilot fornecerá sugestões em tempo real como texto fantasma esmaecido. Você pode aceitar uma sugestão pressionando `Tab` ou descartá-la continuando a digitar. Se você preferir aceitar apenas parte de uma sugestão, use o `Ctrl+Right` atalho (`Cmd+Right` no macOS) para aceitar a próxima palavra. O Copilot também oferece sugestões alternativas para a mesma entrada, que você pode visualizar passando o mouse sobre a sugestão e selecionando o melhor ajuste.

[![Captura de tela do Editor de Consultas do Data Warehouse do Fabric com o preenchimento de código do Copilot.](https://learn.microsoft.com/pt-br/training/wwl/get-started-copilot-fabric-data-warehouse/media/code-completion.png)](https://learn.microsoft.com/pt-br/training/wwl/get-started-copilot-fabric-data-warehouse/media/code-completion.png#lightbox)

Para orientar o Copilot, você pode deixar comentários em sua consulta usando `--`. Por exemplo, escrever `-- What is the distribution of trips by hour on working days (non-holiday weekdays)?` solicita que o Copilot gere uma consulta correspondente. Essa abordagem ajuda você a escrever comentários claros e precisos ao mesmo tempo em que usa o Copilot para criar um código SQL eficiente.

[![Captura de tela do Editor de Consultas do Fabric Data Warehouse com sugestão de comentário do Copilot.](https://learn.microsoft.com/pt-br/training/wwl/get-started-copilot-fabric-data-warehouse/media/comment-suggestion.png)](https://learn.microsoft.com/pt-br/training/wwl/get-started-copilot-fabric-data-warehouse/media/comment-suggestion.png#lightbox)

Copilot pode fornecer sugestões diferentes para a mesma entrada. Você pode passar o mouse sobre a sugestão para visualizar as outras opções.
