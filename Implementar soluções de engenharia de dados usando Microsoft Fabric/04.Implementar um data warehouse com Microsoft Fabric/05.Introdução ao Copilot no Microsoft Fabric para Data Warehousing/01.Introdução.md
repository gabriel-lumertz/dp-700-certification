O Copilot no Fabric na carga de trabalho Data Warehouse aplica IA a tarefas de data warehousing. Ele pode gerar consultas T-SQL, fornecer conclusões de código e informações de superfície com base em seu esquema de warehouse e metadados.

Com recursos como linguagem natural para SQL, ações rápidas para corrigir e explicar consultas e sugestões inteligentes, o Copilot ajuda você a interagir com seu data warehouse de forma mais intuitiva. Seja você um profissional de dados experiente ou apenas começando, o Copilot está aqui para ajudá-lo a desbloquear todo o potencial do data warehouse simplificando tarefas complexas e aumentando sua produtividade.

Neste módulo, você explorará os principais conceitos do Microsoft Fabric e do Copilot no Data Warehouse para aplicar seus recursos em projetos de dados.
