Criar prompts efetivos é essencial. Comece com uma **descrição clara e concisa** das informações específicas que você está procurando e evite uma linguagem ambígua ou excessivamente complexa. Simplifique suas perguntas, mantendo a clareza para garantir que o Copilot possa gerar consultas significativas.

O uso de nomes expressivos e **significativos para tabelas e colunas** em seu data warehouse é crucial. Nomes descritivos ajudam o Copilot a entender o esquema e melhorar a precisão das consultas geradas.

Para consultas complexas que envolvem várias tabelas ou relações, **use comentários** para orientar Copilot e fornecer contexto extra.

**Fornecer contexto** é outro aspecto fundamental. Use uma linguagem natural que se alinhe com seus nomes de tabela e exibição, nomes de coluna, chaves primárias e chaves estrangeiras. Especifique as colunas que você deseja ver, agregações e critérios de filtragem explicitamente. Adicionar comentários na parte superior da consulta (usando `--`) pode orientar ainda mais o Copilot na compreensão da intenção da consulta.

Estabelecer **relações de esquema** na exibição de modelo do seu warehouse aprimora a precisão das instruções JOIN em consultas SQL geradas. Um esquema bem estruturado com relações definidas permite que o Copilot infera conexões entre tabelas com eficiência.

O Copilot pode lidar com erros de digitação ou inferir o contexto com base no esquema, mas é importante garantir que o **esquema seja bem estruturado** e consistente. Isso melhora a confiabilidade geral das consultas geradas.

Atualmente, o idioma natural para SQL dá suporte ao **inglês** para T-SQL. Verifique se os prompts estão escritos em inglês para aproveitar ao máximo esse recurso.

Seguindo essas práticas recomendadas, você pode usar efetivamente o Copilot para simplificar a geração de consultas SQL e melhorar sua produtividade geral.
