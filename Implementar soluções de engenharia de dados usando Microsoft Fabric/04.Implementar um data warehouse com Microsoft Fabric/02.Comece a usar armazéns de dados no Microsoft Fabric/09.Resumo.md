Neste módulo, você aprendeu como os data warehouses usam a modelagem dimensional para organizar dados em tabelas de fatos e dimensões e o que torna um Fabric data warehouse exclusivo. Você explorou a consulta e a transformação de dados com T-SQL e o editor visual de consultas, estruturou as tabelas em um esquema estrela e aplicou recursos de segurança, como segurança em nível de linha e máscara dinâmica de dados, para proteger seus dados.

Sem uma plataforma como Microsoft Fabric, a criação desse tipo de ambiente de warehouse exigiria o provisionamento e o gerenciamento de infraestrutura de SQL dedicada, a configuração de storage e computação separadas e a integração manual de dados entre sistemas silos. Um data warehouse do Fabric elimina essa complexidade combinando recursos T-SQL completos com a integração do OneLake em uma única plataforma governada que dá suporte a experiências tradicionais de análise e de IA.

Para aprender padrões avançados de transformação T-SQL, como fluxos de trabalho de preparo, cargas incrementais e upserts baseados em MERGE, continue para o módulo [Transformar dados usando T-SQL](https://learn.microsoft.com/pt-br/training/modules/modify-data-with-transact-sql/).
