4.Ao projetar uma data warehouse usando a modelagem dimensional em Microsoft Fabric, qual das instruções a seguir descreve melhor a função de uma chave substituta nas tabelas de dimensão?

Uma chave substituta é a mesma que uma chave natural e é usada para vincular tabelas de dimensão a sistemas de origem.

> [!Correct]
> Uma chave substituta é um identificador exclusivo específico do data warehouse, usado para manter a consistência e a precisão.

Uma chave alternativa é uma chave alternativa que identifica instâncias específicas de uma entidade no sistema de origem.
