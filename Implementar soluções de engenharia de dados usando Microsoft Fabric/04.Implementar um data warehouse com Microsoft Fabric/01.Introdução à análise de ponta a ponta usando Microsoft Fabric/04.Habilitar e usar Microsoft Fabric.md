Antes de explorar os recursos de ponta a ponta de Microsoft Fabric, ele deve ser habilitado para sua organização. Talvez seja necessário trabalhar com seu departamento de TI para habilitar o Fabric para sua organização, incluindo uma das seguintes funções:

- _Administrador de Fabric_: gerencia as definições e configurações do Fabric.
- _Administrador do Power Platform_: supervisiona os serviços do Power Platform, incluindo o Fabric.
- _Global administrator_: tem direitos implícitos de administrador do Fabric por meio de permissões em toda a organização.

## Habilitar Microsoft Fabric

Os administradores podem habilitar o Fabric nas configurações do **Admin portal > Tenant** no Power BI service. O Fabric pode ser habilitado para toda a organização ou para grupos de segurança Microsoft 365 ou Microsoft Entra específicos. Os administradores também podem delegar essa capacidade a outros usuários no nível de capacidade.

> [!Observação]
> 
> 
> Se sua organização não estiver usando o Fabric ou Power BI hoje, você poderá se inscrever para uma avaliação do Fabric [free Fabric](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial) para explorar seus recursos.

## Criar workspaces

Workspaces são ambientes colaborativos em que você pode criar e gerenciar itens como lakehouses, armazéns e relatórios. Todos os dados são armazenados no OneLake e acessados por meio de workspaces. Os workspaces também dão suporte à exibição de linhagem de dados, fornecendo uma exibição visual do fluxo de dados e das dependências para aprimorar a transparência e a tomada de decisões.

Nas _configurações do Workspace_, você pode definir:

- Tipo de licença para usar recursos do Fabric.
- Acesso ao OneDrive para o espaço de trabalho.
- Conexão para Armazenamento do Azure Data Lake Gen2.
- Integração do Git para controle de versão.
- Configurações de carga de trabalho do Spark para otimização de desempenho.

Você pode gerenciar o acesso ao workspace por meio de quatro funções: _administrador_, _colaborador_, _membro_ e _visualizador_. Essas funções se aplicam a todos os itens em um workspace e devem ser reservadas para colaboração. Para um controle de acesso mais granular, use permissões no nível do item com base nas necessidades de negócios.

> [!Observação]
> 
> 
> Saiba mais sobre espaços de trabalho na [documentação do Fabric](https://learn.microsoft.com/pt-br/fabric/get-started/workspaces).

## Criar itens utilizando as cargas de trabalho do Fabric

Após ter criado seu workspace habilitado para o Fabric, você poderá começar a criar itens no Fabric. Cada carga de trabalho no Fabric oferece diferentes tipos de item para armazenar, processar e analisar dados. As cargas de trabalho do Fabric incluem:

- **Engenharia de dados**: crie lakehouses e operacionalize fluxos de trabalho para criar, transformar e compartilhar seu patrimônio de dados.
- **Data Factory**: ingerir, transformar e orquestrar dados.
- **Data Warehouse**: combine várias fontes em um armazém tradicional para análise.
- **Real-Time Intelligence**: processar, monitorar e analisar dados de streaming.
- **Industry Solutions**: Use soluções de dados do setor prontas para usar.
- **Ciência de Dados**: detecte tendências, identifique exceções e preveja valores usando machine learning.
- **Bancos de** dados: crie e gerencie bancos de dados com ferramentas para inserir, consultar e extrair dados.
- **IQ (versão prévia)**: unificar dados no OneLake e organizá-los de acordo com o idioma da sua empresa usando ontologias, grafos e modelos semânticos.
- **Power BI**: crie relatórios e dashboards para tomar decisões controladas por dados.

O Fabric integra recursos de ferramentas existentes da Microsoft, como Power BI, Azure Synapse Analytics e Azure Data Factory em uma plataforma unificada. O Fabric também dá suporte a uma arquitetura de malha de dados, permitindo a propriedade de dados descentralizada, mantendo a governança centralizada. Esse design elimina a necessidade de acesso direto a recursos Azure, simplificando os fluxos de trabalho de dados.

## Capacidades de IA no Microsoft Fabric

O Fabric inclui recursos que dão suporte ao desenvolvimento de IA, bem como à produtividade alimentada por IA em cargas de trabalho.

**O IQ do Fabric** (versão prévia) é uma carga de trabalho do Fabric para unificar dados no OneLake e organizá-los de acordo com o idioma da sua empresa. Seu item principal é a **ontologia**, que define seus conceitos de negócios, relações e regras para que os agentes de IA possam raciocinar entre domínios usando linguagem comercial consistente em vez de esquemas de tabela brutos.

Fabric IQ é uma das três cargas de trabalho de IQ que a Microsoft fornece para oferecer aos agentes acesso a diferentes aspectos da organização:

- **Fabric IQ** modela dados de negócios (ontologias, modelos semânticos e grafos) para que os agentes possam raciocinar sobre análises no OneLake e Power BI.
- **Foundry IQ** conecta dados estruturados e não estruturados em Azure, SharePoint, OneLake e na Web para que os agentes possam acessar o conhecimento corporativo com reconhecimento de permissão.
- **O IQ de Trabalho** captura sinais de colaboração de documentos, reuniões, chats e fluxos de trabalho, fornecendo aos agentes informações sobre como sua organização opera.

Cada carga de trabalho de QI é autônoma, mas você pode usá-las em conjunto para fornecer um contexto organizacional abrangente para agentes.

**Os agentes de dados do Fabric** permitem criar interfaces de conversa em que os usuários fazem perguntas sobre dados organizacionais em linguagem natural. Os agentes traduzem essas perguntas em consultas estruturadas nos seus lakehouses, warehouses e modelos semânticos.

Na carga de trabalho do Fabric IQ, os agentes de dados podem se conectar à sua ontologia como fonte, permitindo que eles entendam e usem seus conceitos de negócios ao responder perguntas.

### Copilot para cargas de trabalho

Microsoft Copilot no Fabric é um assistente de IA gerativo disponível em todas as cargas de trabalho do Fabric. Copilot ajuda profissionais de dados e usuários de negócios a concluir tarefas comuns com mais eficiência. As principais funcionalidades incluem:

- **Conclusão e geração de código**: Copilot fornece sugestões de código inteligentes em notebooks, gera consultas SQL a partir de descrições em linguagem natural e traduz perguntas em KQL (Linguagem de Consulta Kusto) para análise em tempo real.
- **Orientação para transformação de dados**: No Data Factory, o Copilot dá suporte tanto a usuários comuns quanto a profissionais na manipulação de dados, proporcionando geração de código para transformação e explicações em linguagem simples sobre lógica complexa.
- **Relatórios e geração de insights**: Em Power BI, o Copilot gera relatórios automaticamente, cria resumos de página e permite que os usuários empresariais façam perguntas sobre seus dados em linguagem natural.

> [!Observação]
> 
> 
> Copilot no Microsoft Fabric está habilitado por padrão. Os administradores podem desabilitar Copilot das configurações do **Admin portal > Tenant** ou controlar o acesso a grupos de segurança específicos ou no nível de capacidade.
