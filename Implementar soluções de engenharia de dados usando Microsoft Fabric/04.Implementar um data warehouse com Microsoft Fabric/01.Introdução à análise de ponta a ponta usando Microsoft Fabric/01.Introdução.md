As organizações precisam ingerir, preparar, governar e analisar dados em escala, muitas vezes entre ferramentas e equipes desconectadas. Cada vez mais, esses mesmos dados também precisam estar prontos para cargas de trabalho de IA, como modelos de machine learning, copilots e agentes inteligentes. O gerenciamento dessas tarefas em sistemas separados cria complexidade, lacunas de governança e esforço duplicado.

Microsoft Fabric é uma plataforma de análise de ponta a ponta que fornece um ambiente único e integrado em que os profissionais de dados e a empresa colaboram em projetos de dados. Criado em um data lake unificado chamado OneLake, o Fabric reúne as ferramentas necessárias em todo esse ciclo de vida.

Como todos os dados são ingeridos, preparados e regidos no Fabric, os mesmos dados que alimentam seus relatórios e dashboards também estão disponíveis para recursos de IA, como Copilot, agentes de dados e IQ do Fabric. Isso significa que o trabalho que você faz para organizar e governar seus dados diretamente dá suporte às iniciativas de IA da sua organização.

Este módulo apresenta a plataforma Fabric, discute para quem o Fabric é, explora cargas de trabalho do Fabric e examina como o Fabric dá suporte à análise e à IA.
