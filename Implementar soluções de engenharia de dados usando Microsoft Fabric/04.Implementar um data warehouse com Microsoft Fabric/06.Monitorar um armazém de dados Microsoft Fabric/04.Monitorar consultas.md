Os data warehouses do Microsoft Fabric incluem o recurso de _insights de consulta_, que fornece informações históricas e agregadas sobre as consultas que foram executadas, permitindo que você identifique consultas usadas com frequência ou de longa execução e ajudando a analisar e ajustar o desempenho da consulta.

Os insights de consulta são fornecidos por meio das seguintes exibições:

- **queryinsights.exec_requests_history**: Detalhes de cada consulta SQL concluída.
- **queryinsights.long_running_queries**: Detalhes do tempo de execução de consulta.
- **queryinsights.frequently_run_queries**: Detalhes de consultas de execução frequente.

## Recuperando insights de consulta

As exibições de insights de consulta são uma fonte útil de informações sobre as consultas que estão sendo executadas em seu data warehouse.

Por exemplo, considere a seguinte consulta:

SQL

```
SELECT start_time, login_name, command
FROM queryinsights.exec_requests_history 
WHERE start_time >= DATEADD(MINUTE, -60, GETUTCDATE())
```

Essa consulta usa a exibição **queryinsights.exec_requests_history** para identificar consultas que foram executadas na hora anterior.

> [!NOTE]
> 
> 
> Dependendo das cargas de trabalho simultâneas, as consultas podem levar até 15 minutos para serem refletidas nas exibições de insights de consulta.

Você pode obter detalhes de consultas de longa duração na exibição **queryinsights.long_running_queries** da seguinte maneira:

SQL

```
SELECT last_run_command, number_of_runs, median_total_elapsed_time_ms, last_run_start_time
FROM queryinsights.long_running_queries
WHERE number_of_runs > 1
ORDER BY median_total_elapsed_time_ms DESC;
```

Essa consulta identifica comandos SQL de longa execução que foram usados mais de uma vez e os retorna em ordem decrescente, de acordo com o tempo médio para conclusão de cada um.

> [!Observação]
> 
> 
> Para permitir que as exibições forneçam métricas agregadas, as consultas com predicados serão parametrizadas e consideradas a mesma consulta se as instruções parametrizadas forem uma correspondência exata. Por exemplo, as seguintes consultas seriam consideradas o mesmo comando:
> 
> `SELECT * FROM sales WHERE orderdate > '01/01/2023'`
> 
> `SELECT * FROM sales WHERE orderdate > '12/31/2021'`

Para localizar consultas comumente usadas, você pode usar a exibição **queryinsights.frequently_run_queries**, da seguinte forma:

SQL

```
SELECT last_run_command, number_of_runs, number_of_successful_runs, number_of_failed_runs
FROM queryinsights.frequently_run_queries
ORDER BY number_of_runs DESC;
```

Essa consulta retorna detalhes de execuções bem-sucedidas e com falha para comandos executados com frequência.

> [!Dica]
> 
> 
> Para obter mais informações sobre como usar insights de consulta, confira **[Insights de consulta no data warehouse do Fabric](https://learn.microsoft.com/pt-br/fabric/data-warehouse/query-insights)** na documentação do Microsoft Fabric.
