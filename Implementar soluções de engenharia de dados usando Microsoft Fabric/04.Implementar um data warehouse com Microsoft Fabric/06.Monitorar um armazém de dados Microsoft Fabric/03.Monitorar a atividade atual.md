Você pode usar DMVs (exibições de gerenciamento dinâmico) para recuperar informações sobre o estado atual do data warehouse. Especificamente, os data warehouses do Microsoft Fabric incluem os seguintes DMVs:

- **sys.dm_exec_connections**: Retorna informações sobre conexões de data warehouse.
- **sys.dm_exec_sessions**: Retorna informações sobre sessões autenticadas.
- **sys.dm_exec_requests**: Retorna informações sobre solicitações ativas.

O esquema dessas tabelas é mostrado aqui:

![Diagrama de exibições de gerenciamento dinâmico.](https://learn.microsoft.com/pt-br/training/wwl/monitor-fabric-data-warehouse/media/dynamic-management-views.png)

## Consultando DMVs

Você pode recuperar informações detalhadas sobre as atividades atuais no data warehouse consultando as _DMVs dm_exec*_. Por exemplo, considere a seguinte consulta:

SQL

```
SELECT sessions.session_id, sessions.login_name,
    connections.client_net_address,
    requests.command, requests.start_time, requests.total_elapsed_time
FROM sys.dm_exec_connections AS connections
INNER JOIN sys.dm_exec_sessions AS sessions
    ON connections.session_id=sessions.session_id
INNER JOIN sys.dm_exec_requests AS requests
    ON requests.session_id = sessions.session_id
WHERE requests.status = 'running'
    AND requests.database_id = DB_ID()
ORDER BY requests.total_elapsed_time DESC
```

Essa consulta retorna detalhes sobre as solicitações ativas no banco de dados atual, ordenadas pela duração da execução, o que pode ser útil para identificar consultas de longa duração que poderiam se beneficiar da otimização. Um exemplo de conjunto de resultados da consulta é mostrado aqui:
