Os data warehouses do Microsoft Fabric são um ativo importante em qualquer organização, e é importante monitorá-los para controlar e gerenciar custos, identificar e resolver problemas de desempenho de consulta e obter insights sobre como os dados estão sendo usados.

Este módulo explorou as seguintes maneiras pelas quais você pode monitorar um data warehouse:

- O aplicativo Métricas de Capacidade do Microsoft Fabric
- Exibições de Gerenciamento Dinâmico
- Exibições de insights de consulta
