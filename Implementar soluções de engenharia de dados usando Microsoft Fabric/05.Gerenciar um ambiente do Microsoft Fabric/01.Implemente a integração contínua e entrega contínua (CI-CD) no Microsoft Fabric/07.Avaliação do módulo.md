1.Qual é a função do Git no processo de CI/CD no Fabric?

O Git é usado para implantar alterações de código em ambientes diferentes.

O Git é usado para teste automatizado de alterações de código.

> [!Correct]
> O Git permite que sua equipe colabore usando branches e fornece controle de versão. Ele ajuda a gerenciar as alterações incrementais de código e ver o histórico do código.

2.Qual é a finalidade de conectar um workspace do Fabric a um repositório Git?

Para implantar automaticamente as alterações feitas no workspace em um ambiente em tempo real.

> [!Correct]
> Para sincronizar o conteúdo entre o workspace e o Git, garantindo que eles tenham o mesmo conteúdo.

Para permitir que vários desenvolvedores trabalhem no mesmo código simultaneamente sem conflitos.

3.Qual é a função principal dos pipelines de implantação no Fabric?

Os pipelines de implantação são usados para criar um novo conteúdo no Fabric.

Os pipelines de implantação são usados para excluir o conteúdo antigo do Fabric.

> [!Correct]
> Os pipelines de implantação automatizam a movimentação de conteúdo por meio dos estágios de desenvolvimento, teste e produção.
