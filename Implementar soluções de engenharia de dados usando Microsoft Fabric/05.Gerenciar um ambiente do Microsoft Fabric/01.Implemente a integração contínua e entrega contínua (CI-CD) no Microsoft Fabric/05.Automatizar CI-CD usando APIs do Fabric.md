As APIs REST do Fabric permitem automatizar procedimentos e processos do Fabric, melhorando a eficiência e a produtividade. A API REST significa Interface de Programação de Aplicativo de Transferência de Estado Representacional. As APIs REST do Azure são usadas para gerenciar e interagir com vários serviços do Azure.

Algumas das vantagens de usar as APIs REST do Fabric são:

- Automatizar os processos de repetição com consistência, facilitando a execução contínua do processamento de dados.
- Integração perfeita com outros sistemas e aplicativos, proporcionando um pipeline de dados simplificado e eficiente.

APIs REST de CI/CD do Fabric estão disponíveis para pipelines de implantação e integração com o Git.

- [APIs REST de pipelines de implantação](https://learn.microsoft.com/pt-br/rest/api/fabric/core/deployment-pipelines)
- [APIs REST do Git](https://learn.microsoft.com/pt-br/rest/api/fabric/core/git)

## Usar as APIs REST do Fabric para CI/CD para automatizar processos

Você pode usar as APIs REST da CI/CD do Fabric para:

- Confirmar as alterações feitas no espaço de trabalho na branch remota conectada.
- Atualizar o espaço de trabalho com os commits enviados para a branch conectada.
- Veja quais itens têm alterações recebidas e quais itens têm alterações que ainda não foram confirmadas no Git com a API de status do Git.
- Listar os Itens da Etapa do Pipeline de Implantação: Retorna os itens com suporte do espaço de trabalho atribuídos à etapa especificada do pipeline de implantação especificado.
- Implantar o Conteúdo da Etapa: Implanta itens da etapa especificada do pipeline de implantação especificado.
