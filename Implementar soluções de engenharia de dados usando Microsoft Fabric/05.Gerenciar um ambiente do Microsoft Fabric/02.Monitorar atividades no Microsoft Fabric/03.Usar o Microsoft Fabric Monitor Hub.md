As ferramentas de visualização facilitam o monitoramento. Eles ajudam a identificar tendências ou anomalias. O Hub monitor é a ferramenta de visualização de monitoramento no Microsoft Fabric. O Hub monitor coleta e agrega dados de itens e processos selecionados do Fabric. Ele armazena dados de atividade do Fabric em uma interface comum para que você possa exibir o status de várias atividades de integração, transformação, movimentação e análise de dados diferentes no Fabric em um só lugar, em vez de monitorar cada uma delas separadamente.

## Atividades exibidas no Hub monitor

Algumas das atividades para as quais você pode ver metadados de monitoramento no Hub do Microsoft Fabric Monitor incluem:

- Histórico de execução do pipeline de dados
- Execuções de fluxo de dados
- Atualizações de modelo semântico e datamart
- Histórico de execução do trabalho e notebook do Spark e detalhes do trabalho

## Exibir o Hub de Monitor

O hub monitor pode ser aberto selecionando **Monitor** no painel de navegação do Fabric.

![Captura de tela da interface do hub do Microsoft Fabric Monitor.](https://learn.microsoft.com/pt-br/training/wwl/monitor-fabric-items/media/monitor-hub.png)

## Exibir detalhes da atividade do Fabric

Cada atividade no Hub monitor pode ser selecionada e várias ações podem ser executadas para a atividade selecionada. As ações variam de acordo com a atividade e incluem opções como: abrir a atividade, tentar novamente, exibir detalhes da atividade ou execuções históricas. Para exibir essas informações, selecione as reticências que aparecem quando você passa o mouse sobre uma atividade.

![Captura de tela da interface de detalhes do hub do Microsoft Fabric Monitor.](https://learn.microsoft.com/pt-br/training/wwl/monitor-fabric-items/media/view-monitor-hub-details.png)

Quando você seleciona **Exibir detalhes**, a tela exibida é personalizada para a atividade selecionada e fornece clareza sobre o que aconteceu durante a atividade. Você pode exibir metadados como:

- Status da atividade
- Hora de início e término
- Duração
- Estatísticas de atividade

## Investigar o que aconteceu durante uma atividade do Fabric

Para investigar o que aconteceu durante uma atividade, algumas atividades no Hub monitor incluem hiperlinks que permitem detalhar os detalhes da execução. Informações são fornecidas sobre quaisquer erros e o êxito ou falha de uma execução. Atividades do Spark entre itens podem ser exibidas. Você pode exibir aplicativos Spark disparados de Notebooks, Definições de Trabalho do Spark e Pipelines. Para obter mais informações, consulte: [Visão geral do monitoramento do Apache Spark](https://learn.microsoft.com/pt-br/fabric/data-engineering/spark-monitoring-overview)
