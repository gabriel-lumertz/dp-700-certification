Em uma solução de análise de dados, você cria, gerencia e otimiza as estruturas para coletar, armazenar, processar e analisar dados. Os dados em sua forma bruta não são significativos para tomar decisões de negócios. Os dados de diferentes fontes devem ser combinados, carregados ou ingeridos em armazenamentos de dados e transformados em formatos úteis para análise. O processo de ingestão e transformação deve ser monitorado para que os erros possam ser identificados e corrigidos antes que afetem os usuários.

O Microsoft Fabric fornece recursos para monitorar atividades do Fabric. Neste módulo, exploraremos como usar o Monitor Hub para monitorar as atividades de ingestão e transformação em seu ambiente do Fabric e como usar o Activator para executar automaticamente ações quando padrões ou condições são detectados na alteração de dados.

Ao final deste módulo, você entenderá os recursos de monitoramento no Microsoft Fabric. Você também poderá concluir um exercício prático usando o Monitor Hub.
