Os workspaces são ambientes onde os usuários podem colaborar para criar grupos de itens. Os itens são os recursos disponíveis para você trabalhar no Fabric, como lakehouses, warehouses e relatórios. As funções de workspace são conjuntos de permissões pré-configuradas que permitem gerenciar o que os usuários podem fazer e acessar em um workspace do Fabric.

As permissões de item controlam o acesso a itens individuais do Fabric em um workspace. As permissões de item permitem ajustar as permissões definidas por uma função de workspace ou conceder a um usuário acesso a um ou mais itens em um workspace, sem a necessidade de adicioná-lo a uma função de workspace.

Vamos ver alguns cenários em que você precisaria configurar o acesso usando funções de workspace e permissões de itens.

## Entender as funções de workspace

Suponha que você trabalhe em uma empresa de saúde como administrador de segurança do Fabric. Você precisará configurar o acesso a um novo engenheiro de dados. Esse engenheiro deve ter permissão para:

- Criar itens do Fabric em um workspace existente
- Ler todos os dados em um lakehouse que está no mesmo workspace onde ele tem permissão para criar itens do Fabric

As funções de workspace controlam o que os usuários podem fazer e acessar dentro de um workspace do Fabric. Existem quatro funções principais que se aplicam a _todos os itens_ dentro de um workspace. As funções de workspace podem ser atribuídas a indivíduos, grupos de segurança, grupos do Microsoft 365 e listas de distribuição. Os usuários podem ser atribuídos às seguintes funções:

- **Administrador**: pode exibir, modificar, compartilhar e gerenciar todo o conteúdo e dados no workspace, além de gerenciar permissões.
- **Membro**: pode exibir, modificar e compartilhar todo o conteúdo e dados no workspace.
- **Colaborador**: pode exibir e modificar todo o conteúdo e dados no workspace.
- **Espectador**: pode apenas visualizar o conteúdo e dados no workspace, sem poder modificá-los.

> [!Dica]
> 
> 
> Para obter uma lista completa das permissões associadas às funções de espaço de trabalho, consulte: [Funções em espaços de trabalho](https://learn.microsoft.com/pt-br/fabric/get-started/roles-workspaces)

Para atender aos requisitos de acesso do novo engenheiro de dados, atribua a ele a função de **Colaborador** no workspace. Isso permitirá que ele modifique o conteúdo no workspace, incluindo a criação de itens do Fabric, como lakehouses. A função de colaborador também permitirá que ele leia dados no lakehouse existente.

### Atribuir funções de workspace

Use o botão **Gerenciar acesso** dentro de um workspace para adicionar usuários às funções de workspace. Adicione um usuário inserindo seu nome e selecionando a função de workspace desejada na caixa de diálogo **Adicionar pessoas**.

[![Captura de tela do clique no botão gerenciar acesso.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/secure-data-access-in-fabric/media/manage-access.png)](https://learn.microsoft.com/pt-br/training/wwl-data-ai/secure-data-access-in-fabric/media/manage-access.png#lightbox)

## Configurar permissões de item

As permissões de item controlam o acesso a itens individuais do Fabric em um workspace. Essas permissões são ideais para conceder acesso a itens específicos em um workspace, sem precisar adicionar os usuários a uma função de workspace Também podem ser usadas junto com funções de workspace para ajustes mais detalhados.

Imagine que, após alguns meses com o acesso de **Colaborador** em um workspace, o engenheiro de dados não precise mais criar novos itens do Fabric e agora precise apenas exibir e ler dados de um único lakehouse.

Como o engenheiro não precisa mais exibir todos os itens no workspace, a função de **Colaborador** pode ser removida. É possível configurar permissões específicas para o lakehouse, permitindo que ele acesse apenas os metadados e dados do lakehouse, sem ver outros itens do workspace. Essa configuração de acesso aos itens garante o princípio de privilégio mínimo, para que o engenheiro só tenha acesso ao que é necessário para desempenhar suas funções de trabalho.

Para compartilhar um item e configurar suas permissões, selecione as reticências (...) ao lado de um item do Fabric dentro de um workspace e, em seguida, clique em **Gerenciar permissões**.

[![Captura de tela da configuração de permissões de item.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/secure-data-access-in-fabric/media/manage-item-permissions.png)](https://learn.microsoft.com/pt-br/training/wwl-data-ai/secure-data-access-in-fabric/media/manage-item-permissions.png#lightbox)

Na janela **Conceder acesso a pessoas** que aparece após selecionar **Gerenciar permissões**, você pode adicionar o usuário e, se não selecionar nenhuma opção em **Permissões adicionais**, o usuário terá acesso de leitura aos metadados do lakehouse. O usuário não terá acesso aos dados subjacentes no lakehouse. Se o engenheiro precisar ler os dados completos e não apenas os metadados, é possível selecionar as opções **Ler todos os dados do ponto de extremidade SQL** ou **Ler todos os dados do Apache Spark**.

[![Captura de tela de concessão de acesso completo de leitura ao lakehouse para pessoas.](https://learn.microsoft.com/pt-br/training/wwl-data-ai/secure-data-access-in-fabric/media/grant-people-access-lakehouse.png)](https://learn.microsoft.com/pt-br/training/wwl-data-ai/secure-data-access-in-fabric/media/grant-people-access-lakehouse.png#lightbox)
