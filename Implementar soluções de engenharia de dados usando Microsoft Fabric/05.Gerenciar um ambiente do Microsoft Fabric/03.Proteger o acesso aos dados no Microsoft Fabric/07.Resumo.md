Neste módulo, você aprendeu a usar os recursos de controle de acesso disponíveis em diversos mecanismos do Fabric para proteger seus dados e garantir que sua equipe tenha o acesso necessário para desempenhar suas funções no Fabric. Você explorou o modelo de segurança multicamadas do Fabric e como usá-lo para gerenciar o acesso a dados.

Os principais pontos deste módulo incluem entender como configurar a segurança para todo o workspace, gerenciar itens de dados individuais no Fabric e aplicar permissões granulares.
