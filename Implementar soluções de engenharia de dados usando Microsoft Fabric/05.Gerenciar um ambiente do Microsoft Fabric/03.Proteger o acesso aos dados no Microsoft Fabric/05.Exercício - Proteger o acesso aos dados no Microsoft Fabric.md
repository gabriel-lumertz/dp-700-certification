Agora é sua chance de proteger o acesso a dados no Microsoft Fabric.

Neste exercício, você aprenderá a proteger o acesso a dados no Fabric usando os conceitos explorados neste módulo.

> [!Observação]
> 
> 
> - Você precisa de uma licença de avaliação do Microsoft Fabric com a versão prévia do Fabric habilitada no locatário. Consulte [**Introdução ao Fabric**](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial) para habilitar sua licença de avaliação do Fabric.
> - Para concluir os exercícios neste laboratório, você precisará de dois usuários: um usuário deve receber a função de Administrador do Workspace e o outro receberá permissões no decorrer deste laboratório. Para atribuir funções a espaços de trabalho, confira [**Conceder acesso ao seu espaço de trabalho**](https://learn.microsoft.com/pt-br/fabric/get-started/give-access-workspaces).

Inicie o exercício e siga as instruções.
