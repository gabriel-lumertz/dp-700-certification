A segurança no Microsoft Fabric é otimizada para proteger dados para casos de uso específicos. Usuários diferentes precisam da capacidade de executar várias ações no Fabric para cumprir as responsabilidades dos cargos deles. O Fabric facilita isso permitindo que você conceda aos usuários acesso a cargas de trabalho de dados específicas por meio de permissões de workspace e item, permissões de computação e funções de acesso a dados do OneLake (versão prévia).

## Proteger dados por caso de uso

Um caso de uso de segurança no Fabric refere-se a um conjunto de usuários que precisam de acesso a dados e acessar dados de uma maneira específica. Depois que um caso de uso é identificado, as permissões do Fabric associadas a esse caso de uso podem ser configuradas. Suponha que você trabalhe em uma empresa de saúde com vários sistemas que armazenam dados, como EHR (registros eletrônicos de saúde), dados de declarações de seguro, dados de avaliação clínica, registros de pacientes e de doenças e dados administrativos. Diferentes usuários em sua empresa ou organizações parceiras precisam exibir, transformar, analisar, agregar e usar esses dados para derivar insights de negócios. Os usuários precisam de acesso a diferentes mecanismos de computação, itens e workspaces do Fabric para executar os trabalhos deles com eficiência:

- Os **engenheiros de dados** precisam de acesso aos dados em um lakehouse para criarem produtos de dados downstream.
- **Analistas de dados ou de** negócios precisam consultar dados para responder a perguntas comerciais.
- Os **cientistas de dados** precisam acessar dados em um lakehouse e consumi-los pelo Apache Spark para criar modelos e experimentos.
- **Os criadores** de relatórios precisam criar relatórios para compartilhar com os consumidores de relatório.
- **Os consumidores** de relatório precisam exibir dados em relatórios do Power BI para tomar decisões.

Neste módulo, você aprenderá a usar os recursos de controle de acesso do Fabric disponíveis para proteger seus dados e fornecer à sua equipe o acesso necessário no Fabric para que executem as funções relacionadas ao trabalho deles. Você explorará o modelo de segurança multicamada do Fabric e como usá-lo para gerenciar o acesso a dados.

Ao final deste módulo, você saberá como configurar a segurança para um workspace inteiro, para itens de dados individuais do Fabric e como aplicar permissões granulares em itens de dados do Fabric.
