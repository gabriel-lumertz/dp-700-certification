Com o Microsoft Fabric, é possível criar pipelines que encapsulam processos complexos de ingestão e transformação de dados. Os pipelines fornecem uma maneira eficaz de orquestrar tarefas de processamento de dados que podem ser executadas sob demanda ou em intervalos agendados.


> [!Dica]
> Para saber mais sobre os pipelines no Microsoft Fabric, confira [Pipelines de dados](https://learn.microsoft.com/pt-br/fabric/data-factory/data-factory-overview) na documentação do Microsoft Fabric.
