É possível definir pipelines com qualquer combinação de atividades escolhidas, a fim de criar processos de ingestão e transformação de dados personalizados para atender às suas necessidades específicas. No entanto, há muitos cenários de pipeline comuns para os quais o Microsoft Fabric inclui modelos de pipeline predefinidos que podem ser usados e personalizados conforme necessário.

Para criar um pipeline com base em um modelo, selecione o bloco **Modelos** em um novo pipeline, conforme mostrado aqui.

![Captura de tela do bloco Escolher uma tarefa para iniciar.](https://learn.microsoft.com/pt-br/training/wwl/use-data-factory-pipelines-fabric/media/start-pipeline.png)

Selecionar essa opção exibe uma seleção de modelos de pipeline, conforme mostrado aqui.

![Captura de tela dos modelos de fluxo de trabalho.](https://learn.microsoft.com/pt-br/training/wwl/use-data-factory-pipelines-fabric/media/pipeline-templates.png)

É possível selecionar o modelo mais apropriado para suas necessidades e editar o pipeline na respectiva tela para personalizá-lo de acordo com suas necessidades.
