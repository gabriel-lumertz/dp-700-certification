Este módulo apresentou um cenário em que engenheiros de dados precisam ingerir, transformar e carregar dados em um armazenamento de dados do Fabric, como um lakehouse. Também foi identificado que os analistas de dados precisam realizar as transformações mais próximo da fonte de dados para dar suporte ao desenvolvimento de relatórios do Power BI.

Com o Microsoft Fabric, é possível criar Dataflows Gen2 para realizar a integração de dados para o lakehouse e, opcionalmente, também incluir o fluxo de dados em um pipeline de dados. Você aprendeu sobre Dataflows Gen2 e como usá-los como parte do processo de integração de dados. O Power Query Online oferece uma interface visual para executar transformações de dados complexas sem escrever códigos.

Para saber mais sobre a integração de dados, confira a documentação do [Data Factory no Microsoft Fabric](https://learn.microsoft.com/pt-br/fabric/data-factory/).
