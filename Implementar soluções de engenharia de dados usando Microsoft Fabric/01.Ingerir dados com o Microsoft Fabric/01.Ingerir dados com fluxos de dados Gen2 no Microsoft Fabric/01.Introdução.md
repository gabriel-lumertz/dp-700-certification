O Microsoft Fabric oferece uma solução unificada para engenharia, integração e análise de dados. Uma etapa essencial na análise de ponta a ponta é a ingestão de dados. Os Fluxos de Dados Gen2 são usados para ingerir e transformar dados de várias fontes e, em seguida, colocar os dados limpos em outro destino. Eles podem ser incorporados em pipelines de dados para orquestração de atividades mais complexas e também usados como uma fonte de dados no Power BI.

Imagine que você trabalha para uma empresa de varejo com lojas em todo o mundo. Como engenheiro de dados, você precisa preparar e transformar dados de várias fontes em um formato adequado para análises de dados e geração de relatórios. A empresa solicita um modelo de dados que consolida fontes de dados distintas das diferentes lojas. Os Fluxos de Dados Gen2 permitem que você prepare os dados para garantir a consistência e, em seguida, coloque-os em um destino preferencial. Eles também habilitam a reutilização e facilitam a atualização dos dados. Sem um fluxo de dados, seria preciso extrair e transformar manualmente os dados de cada fonte, o que é demorado e pode resultar em erros.

Neste módulo, explicaremos como usar os Fluxos de Dados Gen2 no Microsoft Fabric para atender às suas necessidades de ingestão de dados.
