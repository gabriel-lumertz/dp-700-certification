Os fluxos de dados de Gen2 fornecem uma excelente opção para transformações de dados no Microsoft Fabric. A combinação de fluxos de dados e pipelines é útil quando você precisa executar operações adicionais nos dados transformados.

Os pipelines de dados são um conceito comum na engenharia de dados e oferecem uma ampla variedade de atividades para orquestração. Algumas atividades comuns incluem o seguinte:

- Copiar dados
- Incorporar fluxos de dados
- Adicionar notebooks
- Obter metadados
- Executar um script ou procedimento armazenado

Os pipelines fornecem uma maneira visual de concluir atividades em uma ordem específica. É possível usar um fluxo de dados para ingestão e transformação de dados e terminar em um armazenamento de dados do Fabric. Em seguida, é possível incorporar o fluxo de dados em um pipeline para orquestrar atividades adicionais, como executar scripts ou procedimentos armazenados após a conclusão do fluxo de dados.

Os pipelines também podem ser agendados ou ativados por um gatilho para executar o fluxo de dados. Usando um pipeline para executar seu fluxo de dados, você pode atualizar os dados quando precisar, em vez de ter que executar manualmente o fluxo de dados. Quando você está lidando com dados corporativos ou que mudam com frequência, a automação permite que você se concentre em outras responsabilidades.
