Quando você cria um Eventhouse, um banco de dados KQL padrão é criado automaticamente com o mesmo nome. Um Eventhouse contém um ou mais bancos de dados KQL, onde você pode criar tabelas, procedimentos armazenados, exibições materializadas, funções, fluxos de dados e atalhos para gerenciar seus dados. Você pode usar o banco de dados KQL padrão ou criar outros bancos de dados KQL conforme necessário.

Há várias maneiras de acessar e trabalhar com dados em um banco de dados KQL em um Eventhouse:

## Consultar dados em um banco de dados KQL

Para consultar dados em um banco de dados KQL, você pode usar **KQL** ou **T-SQL** em _conjuntos de consultas KQL_. Quando você cria um banco de dados KQL, um conjunto de consultas KQL anexado é criado automaticamente para executar e salvar consultas.

### Sintaxe básica do KQL

O KQL usa uma abordagem de pipeline, em que os dados fluem de uma operação para a outra usando o caractere de barra vertical (`|`). Pense nele como um funil: você começa com uma tabela de dados inteira e cada operador filtra, reorganiza ou resume os dados antes de passá-los para a próxima etapa. A ordem dos operadores é importante porque cada etapa se baseia nos resultados da etapa anterior.

> [!Importante]
> 
> 
> O KQL diferencia maiúsculas de minúsculas para tudo, incluindo nomes de tabela, nomes de coluna, nomes de função, operadores, palavras-chave e valores de cadeia de caracteres. Todos os identificadores precisam ser uma correspondência exata. Por exemplo, `TaxiTrips` é diferente de `taxitrips` ou `TAXITRIPS`.

Confira um exemplo que mostra o conceito de funil:

kql

```
TaxiTrips
| where fare_amount > 20
| project trip_id, pickup_datetime, fare_amount
| take 10
```

Essa consulta começa com todos os dados na tabela `TaxiTrips`, filtra-os para mostrar apenas viagens com tarifas acima de US$ 20, seleciona colunas específicas usando o operador **project** e usa o operador **take** para retornar as primeiras 10 linhas que correspondem aos critérios da cláusula **where**.

A consulta KQL mais simples consiste em um nome de tabela:

kql

```
TaxiTrips
```

Isso retorna todas as colunas da tabela `TaxiTrips`, mas o número de linhas exibidas é limitado pelas configurações padrão da ferramenta de consulta.

Para recuperar uma amostra de dados de tabelas potencialmente grandes, use o operador **take**:

kql

```
TaxiTrips
| take 100
```

Isso retorna as primeiras 100 linhas da tabela `TaxiTrips`, o que é útil para explorar a estrutura de dados sem processar toda a tabela.

Você também pode agregar os dados:

kql

```
TaxiTrips
| summarize trip_count = count() by taxi_id
```

Isso retorna uma tabela de resumo que mostra o número total de corridas (`trip_count`) para cada `taxi_id` exclusiva, contando efetivamente quantas corridas cada táxi fez.

## Analisar dados com o conjunto de consultas KQL

O conjunto de consultas KQL fornece um workspace para executar e gerenciar consultas em bancos de dados KQL. O conjunto de consultas KQL permite que você salve consultas para uso futuro, organize várias guias de consulta e compartilhe consultas com outras pessoas para colaboração. O conjunto de consultas KQL também dá suporte a consultas T-SQL, permitindo que você use a sintaxe T-SQL junto com o KQL para a análise de dados.

Você também pode criar visualizações de dados ao explorar seus dados, renderizando os resultados da consulta como gráficos, tabelas e outros formatos visuais.
