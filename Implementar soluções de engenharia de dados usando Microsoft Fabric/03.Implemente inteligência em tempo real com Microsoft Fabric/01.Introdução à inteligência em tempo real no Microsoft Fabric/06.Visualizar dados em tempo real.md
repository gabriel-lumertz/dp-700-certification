Real-Time Dashboards fornecem uma maneira de fixar visualizações de dados em uma única interface visual, permitindo que você visualize insights em tempo real rapidamente. Cada _bloco_ em um painel mostra informações diferentes com base em uma consulta KQL que extrai dados em tempo real de tabelas em uma casa de eventos.

[![Captura de tela de um painel em tempo real no Microsoft Fabric.](https://learn.microsoft.com/pt-br/training/wwl/get-started-kusto-fabric/media/dashboard.png)](https://learn.microsoft.com/pt-br/training/wwl/get-started-kusto-fabric/media/dashboard.png#lightbox)

## Crie um dashboard em tempo real

Você pode criar um Painel em Tempo Real em um workspace e, em seguida, configurar sua origem ou criar um diretamente de um conjunto de consultas KQL em uma casa de eventos.

Os painéis são compostos por um ou mais _blocos_, cada um contendo uma visualização com base em uma expressão de consulta KQL. Por padrão, a visualização mostra os resultados da consulta como uma tabela; mas você pode editar o bloco para personalizar como os dados são exibidos.

Quando publicados, os blocos permitem explorar os dados que eles contêm interativamente, detalhando os dados e usando uma interface visual para filtrar e agregar os dados e alterar o tipo de visualização.
