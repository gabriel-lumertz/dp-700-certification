Neste módulo, você aprendeu como o Microsoft Fabric Real-Time Intelligence permite ingerir, transformar, armazenar, visualizar e agir sobre dados em movimento. Você explorou o Hub em Tempo Real para descobrir fluxos, eventstreams para ingestão e processamento de dados de eventos e bancos de dados KQL em Eventhouses para análise rápida e baseada em tempo usando KQL. Você também aprendeu a visualizar insights de streaming com painéis em tempo real e o Power BI e como automatizar respostas usando o Activator.
