À medida que as organizações geram volumes crescentes de dados controlados por eventos, a capacidade de processar, analisar e agir sobre dados em movimento torna-se essencial para obter vantagem competitiva. Real-Time Intelligence fornece recursos abrangentes para trabalhar com dados de streaming com latência mínima.

## Explorar casos de uso do Real-Time Intelligence

Ao contrário dos sistemas de lote que processam dados em intervalos agendados, o Real-Time Intelligence ajuda você a responder a eventos à medida que eles acontecem, fornecendo insights quase em tempo real.

Aqui estão alguns tipos comuns de dados de eventos e exemplos de como o Real-Time Intelligence pode dar suporte a ações downstream e capacidade de resposta de negócios:

- **Acompanhamento de entrega**: monitorar os locais do veículo para alertar os clientes quando os pacotes estão atrasados
- **Monitoramento de equipamentos**: controlar a temperatura do computador para evitar avarias dispendiosas
- **Detecção de fraudes**: analisar padrões de compra para bloquear transações suspeitas imediatamente
- **Desempenho do site**: monitorar os tempos de carregamento da página para melhorar a experiência do usuário
- **Integridade do sistema**: acompanhar erros de aplicativo para manter a confiabilidade do serviço

## Componentes do Real-Time Intelligence

O Real-Time Intelligence do Microsoft Fabric é um conjunto integrado de componentes que trabalham juntos para lidar com dados de streaming da captura por meio de resposta automatizada.

[![Diagrama das funcionalidades do Fabric Real-Time Intelligence.](https://learn.microsoft.com/pt-br/training/wwl/get-started-kusto-fabric/media/real-time-intelligence-core.png)](https://learn.microsoft.com/pt-br/training/wwl/get-started-kusto-fabric/media/real-time-intelligence-core.png#lightbox)

O diagrama mostra como os componentes do Real-Time Intelligence funcionam juntos para processamento de ponta a ponta. Cada componente manipula um estágio específico do processo de análise em tempo real:

## Ingerir e processar dados em movimento com Eventstreams

A ingestão e o processamento de dados podem ocorrer por meio **de Eventstreams**, que capturam dados de streaming de várias fontes e aplicam transformações em tempo real à medida que os dados fluem pelo sistema. Os fluxos de eventos podem filtrar, enriquecer e transformar seus dados e roteá-los para destinos diferentes.

## Armazenar dados em tempo real em um Eventhouse

Real-Time Intelligence armazena dados em bancos de dados KQL (Linguagem de Consulta Kusto) em **Eventhouses**. Esses bancos de dados são projetados para dados de série temporal e ingestão rápida de dados de streaming. O armazenamento se integra ao OneLake, disponibilizando seus dados para outras ferramentas do Fabric.

## Analisar dados com o conjunto de consultas KQL

**O KQL Queryset** fornece um workspace para executar e gerenciar consultas em bancos de dados KQL. O conjunto de consultas KQL permite que você salve consultas para uso futuro, organize várias guias de consulta e compartilhe consultas com outras pessoas para colaboração. O conjunto de consultas KQL também dá suporte a consultas T-SQL, permitindo que você use sintaxe SQL familiar junto com KQL para análise de dados.

## Visualizar insights com o Painel de Real-Time

**Real-Time Dashboards** se conectam diretamente aos bancos de dados KQL e são atualizados automaticamente à medida que novos dados chegam. Esses painéis permitem explorar dados interativamente e monitorar as condições atuais e as tendências históricas.

## Agir sobre dados com o Activator

Ações automatizadas podem ser configuradas com **o Activator**, que monitora continuamente os dados de streaming em relação a regras e limites definidos pelo usuário. Quando as condições são atendidas, o Activator pode enviar notificações, disparar fluxos de trabalho no Power Automate, executar pipelines de dados ou notebooks do Fabric, criando automação controlada por eventos que responde a condições em tempo real.

## Descobrir dados de streaming com o hub Real-Time

O **Hub de Real-Time** do Fabric é um ponto central onde você pode descobrir e gerenciar todos os dados em trânsito aos quais tem acesso. Ele oferece uma maneira de ingerir dados de streaming do Azure e de fontes externas e permite que você assine eventos do Azure e do Fabric.

Pense no hub Real-Time como seu catálogo de dados de streaming, onde você pode ver o que está acontecendo quase em tempo real em toda a sua organização. Há conectores que você pode usar para ingerir dados no Microsoft Fabric de várias fontes. Por exemplo, você pode se conectar a fluxos de sensores de IoT por meio dos Hubs de Eventos do Azure, assinar eventos do Armazenamento de Blobs do Azure, usar o CDC (Change Data Capture) para transmitir alterações de banco de dados ou monitorar eventos de workspace do Fabric.

Depois de configurar uma conexão com a fonte de dados ou a fonte de eventos, esses itens se tornam a base para a tomada de decisões controlada por eventos e uma ampla gama de soluções de análise em tempo real, desde a criação de painéis e a configuração de alertas até o acionamento de fluxos de trabalho automatizados e a análise de tendências em seus dados.

[![Captura de tela do hub de Real-Time do Microsoft Fabric.](https://learn.microsoft.com/pt-br/training/wwl/get-started-kusto-fabric/media/real-time-hub.png)](https://learn.microsoft.com/pt-br/training/wwl/get-started-kusto-fabric/media/real-time-hub.png#lightbox)

Para acessar o hub em tempo real, selecione o ícone em **tempo real** na barra de menus principal do Fabric.

O hub em tempo real organiza dados em movimento em várias categorias principais:

- **Fontes de dados**: navegue e conecte-se a fontes de dados de streaming disponíveis, como fontes da Microsoft, feeds de captura de dados de alteração de banco de dados e fontes externas de outros provedores de nuvem
- **Fontes do Azure**: descobrir e configurar fontes de dados de streaming do Azure, como Hub IoT do Azure, Barramento de Serviço do Azure, BD do Azure Data Explorer e muito mais
- **Eventos de malha**: assine eventos gerados pelo sistema no Fabric que você pode acessar, como alterações de status do trabalho, eventos produzidos por ação em arquivos ou pastas no OneLake e alterações de item de workspace do Fabric
- **Eventos do Azure**: assinar eventos do sistema de serviços do Azure que podem ser usados para disparar respostas automatizadas, como ações em arquivos ou pastas no armazenamento de blobs do Azure

No hub Real-Time, você pode visualizar e explorar seus dados de streaming navegando diretamente para fluxos de eventos ou bancos de dados KQL em casas de eventos para análise e consulta mais profundas. Você também pode criar respostas automatizadas usando regras do _Activator_ que disparam ações como notificações, fluxos de trabalho ou processamento de dados quando padrões específicos são detectados.
