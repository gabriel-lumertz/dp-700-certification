Imagine que você é analista de uma empresa de compartilhamento de bicicletas que opera em bairros de uma cidade. À medida que as bicicletas são alugadas e retornadas ao longo do dia, sua empresa precisa monitorar a disponibilidade atual das bicicletas e a capacidade do cais para tomar decisões operacionais, como redistribuir bicicletas para áreas de alta demanda.

Você pode usar Painéis em Tempo Real no Microsoft Fabric para monitorar essas mudanças de dados. Real-Time Dashboards se conectam a bancos de dados KQL em casas de eventos e exibem visualizações que são atualizadas automaticamente para mostrar os dados atuais. Ao contrário dos relatórios tradicionais que mostram instantâneos históricos, os painéis Real-Time podem ser configurados para atualizar com frequência, permitindo que você monitore as condições de alteração e responda às informações atuais.

Neste módulo, você aprenderá a criar painéis Real-Time no Microsoft Fabric e conectá-los a bancos de dados KQL que contêm seus dados.
