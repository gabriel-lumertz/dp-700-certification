Neste módulo, você aprendeu a criar painéis Real-Time no Microsoft Fabric e conectá-los a fontes de dados. Você também aprendeu a adicionar e configurar blocos para visualizar dados em tempo real usando consultas KQL e organizar o conteúdo do painel usando várias páginas para agrupamento lógico.

Você também descobriu como adicionar parâmetros interativos para filtrar dinamicamente os dados do painel e configurar a atualização automática para manter os dados atualizados automaticamente. Por fim, você aprendeu a usar consultas base para melhorar a manutenção quando vários blocos compartilham dados relacionados. Real-Time Dashboards são um componente fundamental dos recursos de inteligência de Real-Time do Microsoft Fabric, permitindo que você forneça aos usuários visualizações de dados atuais que dão suporte à tomada de decisões sensíveis ao tempo à medida que os eventos ocorrem.
