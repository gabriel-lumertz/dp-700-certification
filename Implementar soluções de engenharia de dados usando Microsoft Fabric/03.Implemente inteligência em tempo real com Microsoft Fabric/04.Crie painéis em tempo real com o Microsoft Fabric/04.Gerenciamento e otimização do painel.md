Quando vários blocos em um painel usam dados relacionados, você pode melhorar a manutenção definindo _consultas base_ que recuperam um conjunto geral de registros relevantes para vários blocos. Consultas específicas de bloco então filtram ou agrupam esses dados para visualizações particulares.

As consultas base ajudam a evitar a duplicação da mesma lógica em vários blocos. Em vez de escrever consultas semelhantes para cada bloco, você cria uma consulta base e faz referência a ela a partir de vários blocos.

Por exemplo, em um painel de aluguel de bicicletas, você pode criar uma consulta base por meio do menu **de consultas base** do painel. Ao criar a consulta base, você:

1. Atribua-lhe o nome da variável `_base_bike_data`
2. Defina uma consulta que retorna todos os campos de dados em cada bairro nos últimos 30 minutos:

kql

```
bikes
| where ingestion_time() between (ago(30min) .. now())
| summarize latest_observation = arg_max(ingestion_time(), *) by Neighbourhood
```

[![Captura de tela mostrando uma configuração de consulta base.](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/base-query.png)](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/base-query.png#lightbox)

Em seguida, você pode criar consultas de bloco individuais que fazem referência a essa consulta base usando seu nome de variável:

kql

```
_base_bike_data
| project Neighbourhood, latest_observation, No_Bikes, No_Empty_Docks
| order by Neighbourhood asc
```
