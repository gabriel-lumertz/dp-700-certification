Os Dashboards em Tempo Real no Microsoft Fabric são construídos com fontes de dados de streaming em tempo real. Cada painel consiste em um ou mais _blocos_, cada um exibindo uma visualização de dados em tempo real.

[![Captura de tela de um Dashboard em Tempo Real.](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/dashboard.png)](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/dashboard.png#lightbox)

## Crie um dashboard em tempo real

Para criar um painel em tempo real, você precisará de uma fonte de dados em tempo real, como um banco de dados KQL em uma central de eventos. Em seguida, você pode criar um painel de Real-Time com uma _fonte de dados_ que faz referência ao banco de dados KQL.

### Configurar autorização para fontes de dados

Ao conectar o painel à fonte de dados, você pode especificar quem tem permissão para acessar os dados:

- **Identidade de passagem** – Cada pessoa que exibe o painel acessa os dados usando suas próprias permissões.
- **Identidade do editor do painel** – Todos que exibem o painel acessam dados usando as permissões do criador do painel.

### Criar azulejos

Um dashboard contém pelo menos um bloco, no qual os resultados de uma consulta KQL são exibidos.

### Especificar uma consulta

Ao adicionar um bloco pela primeira vez, você pode inserir e testar a consulta que deseja usar para consultar a fonte de dados subjacente. Por exemplo, você pode usar uma consulta KQL semelhante ao exemplo a seguir para consultar uma tabela chamada **bicicletas** e recuperar detalhes de bicicletas disponíveis e docas de estacionamento de bicicletas vazias para um sistema de aluguel de bicicletas em uma cidade:

kql

```
bikes
| where ingestion_time() between (ago(30min) .. now())
| summarize latest_observation = arg_max(ingestion_time(), *) by Neighbourhood
| project Neighbourhood, latest_observation, No_Bikes, No_Empty_Docks
| order by Neighbourhood asc
```

A consulta no exemplo recupera a observação mais recente (o registro mais recente ingerido na tabela de origem) nos últimos 30 minutos para cada bairro.

Inicialmente, o bloco exibe os resultados da consulta como uma tabela, conforme mostrado na imagem a seguir.

[![Captura de tela de um painel com um bloco que contém uma tabela.](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/tile-table.png)](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/tile-table.png#lightbox)

### Visualizar os dados

Depois de criar um bloco, você pode editá-lo para definir um visual no qual os dados são representados como um gráfico, um mapa ou outra visualização de dados. Por exemplo, pode fazer mais sentido exibir os dados de bicicletas de aluguel como um gráfico de barras que mostra o número de bicicletas e docas de estacionamento vazias em cada bairro.

[![Captura de tela de um bloco que está sendo editado para incluir um gráfico de barras.](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/tile-bar-chart.png)](https://learn.microsoft.com/pt-br/training/wwl/create-real-time-dashboards-microsoft-fabric/media/tile-bar-chart.png#lightbox)

Você pode adicionar vários blocos a um dashboard e organizá-los para organizar a maneira como os dados são visualizados. Você também pode adicionar _blocos de texto_ para fornecer informações adicionais.
