Agora é sua vez de trabalhar com o Microsoft Fabric Activator.

Neste exercício, você cria um Activator que monitora dados e configura regras de detecção que enviam alertas de email automaticamente. Você cria objetos, define filtros e configura respostas automatizadas.

> [!Observação]
> 
> 
> Você precisa de uma [versão de avaliação do Microsoft Fabric](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial) para concluir este exercício.

Inicie o exercício e siga as instruções.
