Imagine que você gerencie a entrega de pacotes para uma empresa com medicamentos sensíveis à temperatura que devem permanecer frios durante o transporte. Você controla as leituras de temperatura e o status de entrega de seus caminhões e precisa tomar medidas imediatas quando as variações de temperatura ameaçam a segurança dos medicamentos. O ativador no Microsoft Fabric pode ajudá-lo a avaliar automaticamente essas condições e disparar ações como alertar sua equipe de expedição ou iniciar fluxos de trabalho que podem iniciar alterações de entrega quando ocorrerem problemas.

## O que é o Activator?

O Activator é o mecanismo de detecção de eventos e regras do Microsoft Fabric no Real-Time Intelligence.

Para usar o Activator, primeiro você se conecta a fontes de dados em tempo real. Em seguida, você cria **regras** para verificar se há condições específicas e, quando essas condições são atendidas, o Activator executa **ações** como enviar alertas de email, postar mensagens do Teams, iniciar fluxos do Power Automate ou executar notebooks do Fabric.

## Cenários do mundo real

O ativador é útil em cenários em que as respostas oportunas importam:

- **As operações de fabricação** podem alertar automaticamente as equipes de manutenção quando as temperaturas dos equipamentos excedem os intervalos operacionais seguros
- **Os gerentes da cadeia** de suprimentos podem ser notificados quando as remessas se desviam de rotas planejadas ou sofrem atrasos inesperados
- **Os gerentes de varejo** podem disparar reordenações de estoque quando os níveis de estoque ficam abaixo dos limites críticos
- **As equipes de operações de TI** podem reiniciar automaticamente os serviços quando as métricas de desempenho indicam degradação do sistema
- **Instituições financeiras** podem sinalizar padrões de transação incomuns para revisão imediata
- **As instalações de** saúde podem alertar a equipe quando os dispositivos de monitoramento de pacientes detectam alterações críticas

Neste módulo, você aprenderá a conectar o Activator às fontes de dados de streaming, criar regras que detectam automaticamente condições importantes e configurar as ações que devem ser disparadas quando essas condições ocorrerem.
