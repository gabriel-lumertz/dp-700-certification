O recurso Eventstream no Fabric funciona criando um pipeline que ingere eventos de fontes de dados de streaming, os processa por meio de transformações opcionais e os entrega para vários destinos. O Eventstream é o mecanismo de entrega que transporta os eventos do local onde eles ocorrem até o local onde precisam ser processados, analisados ou usados para ações.

Você pode usar a canvas do eventstream, que é um editor visual, para projetar seu pipeline arrastando e soltando diferentes nós, tais como fontes, transformações e destinos. Você também pode ver os dados do evento fluindo pelo pipeline em tempo real. Você não precisa escrever nenhum código ou gerenciar qualquer infraestrutura para usar o Eventstream.

Esses dados são armazenados em uma tabela em um Eventhouse chamado **Bikes-by-street-table**.

Os principais componentes de um fluxo de eventos são:

- **Fontes**: As fontes são de onde os dados do evento vêm. Você pode transmitir dados de fontes da Microsoft e também ingerir dados de plataformas que não são da Microsoft.
- **Transformações**: você pode transformar os dados conforme eles fluem em um Eventstream, permitindo filtrar, resumir e reorganizá-los antes de armazená-los. Os exemplos de transformações disponíveis incluem: código SQL, filtro, gerenciar campos, agregar, agrupar por, expandir e ingressar.
- **Destinos**: os destinos são onde os dados de eventos transformados vão para armazenamento, processamento adicional, alertas ou integração com outros sistemas. Você pode rotear os dados do seu fluxo para vários destinos, como tabelas em um Eventhouse ou lakehouse, pontos de extremidade personalizados, fluxos derivados para mais processamento ou o Ativador do Fabric para disparar ações.
