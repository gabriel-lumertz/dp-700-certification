Os dados brutos de streaming raramente chegam no formato exato necessário para análise ou ação. As transformações permitem limpar, enriquecer e remodelar dados antes de roteá-los para destinos, garantindo que cada ponto de extremidade receba dados otimizados para sua finalidade específica.

Cenários comuns de transformação incluem:

- **Qualidade dos dados**: filtrar dados inválidos ou incompletos antes do processamento
- **Roteamento baseado em conteúdo**: rotear subconjuntos de dados diferentes para destinos apropriados com base nos valores de dados reais ou no conteúdo
- **Enriquecimento de** dados: adicionar campos calculados, renomear colunas para maior clareza ou converter tipos de dados para compatibilidade downstream
- **Agregação e resumo**: calcular totais, médias ou contagens em execução ao longo das janelas de tempo para exibições do painel
- **Padronização de formato**: verifique a estrutura de dados consistente em várias fontes de dados antes de combinar fluxos

## Transformar dados de evento

A tela eventstream oferece uma maneira de criar fluxos de trabalho de processamento de dados de eventos. O Eventstream fornece várias transformações sem código que você pode arrastar para a tela:

- **Filtro**: filtrar eventos com base no valor de um campo na entrada. Mantenha somente eventos que atendam a condições específicas. Por exemplo: temperatura > 80°, status = "erro", tipo de cliente = "premium".
- **Gerenciar campos**: essa transformação permite que você adicione, remova, altere o tipo de dados ou renomeie campos provenientes de uma entrada ou de outra transformação. Adicione campos calculados, remova colunas desnecessárias, renomeie campos ou altere os tipos de dados para corresponder aos requisitos de destino.
- **Agregação**: use a transformação de agregação para calcular uma agregação (Soma, Mínimo, Máximo ou Média) sempre que um novo evento ocorrer durante um período de tempo. Essa operação também permite renomear colunas calculadas e filtrar a agregação com base em outras dimensões em seus dados. Você pode ter uma ou mais agregações na mesma transformação.
- **Agrupar por**: Calcular agregações entre eventos em janelas de tempo, por exemplo, totais de vendas por hora ou médias de temperatura diárias. Essa transformação dá suporte a várias janelas de tempo, incluindo _janelas em cascata_ (intervalos fixos) e _janelas deslizantes_ (intervalos sobrepostos).
- **União**: use a transformação união para conectar dois ou mais nós na tela do evento e adicionar eventos com campos compartilhados (com o mesmo nome e tipo de dados) em uma tabela. Os campos que não correspondem são descartados e não incluídos na saída.
- **Junção**: combine dados de dois fluxos com base em uma condição correspondente entre eles.
- **Expanda**: use essa transformação de matriz para criar uma nova linha para cada valor dentro de uma matriz.

## Criar fluxos de trabalho de transformação

As transformações podem ser usadas em conjunto para criar pipelines de processamento de dados. Por exemplo, se você tiver um fluxo de leituras de temperatura do equipamento, poderá começar usando **o filtro** para remover erros de sensor dos dados de IoT de entrada. Em seguida, você pode usar **campos de gerenciamento** para adicionar uma coluna de "prioridade" calculada com base nos limites de temperatura. Em seguida, **agrupar por** poderia calcular médias por hora por local. Por fim, você rotearia os dados processados para destinos apropriados: dados de temperatura para o Fabric Activator para avaliação de regras e resumos por hora para um Lakehouse para análise histórica.
