_O Eventstream_ no Real-Time Intelligence permite que você capture, transforme e roteie eventos em tempo real sem precisar escrever nenhum código. Você pode configurar fontes de eventos, destinos e transformações no fluxo de eventos, permitindo que você colete e, opcionalmente, processar dados antes de roteá-los para um destino.

Alguns dos principais benefícios do Eventstream no Fabric são:

- Você pode capturar, transformar e rotear dados para vários destinos. Você pode usar o recurso arrastar e soltar para criar sua lógica de processamento de dados de evento sem escrever nenhum código.
- Há vários conectores de origem para ingerir dados de eventos de diferentes fontes, como Hubs de Eventos do Azure, Hub IoT do Azure, Armazenamento do Azure, Apache Kafka e outros.
- Você pode enviar dados para uma ampla variedade de destinos para armazenamento, análise adicional ou processamento.

Neste módulo, você aprenderá a criar fluxos de eventos e usá-los para ingerir e transformar dados em movimento e roteá-los para destinos para processamento e análise adicionais.
