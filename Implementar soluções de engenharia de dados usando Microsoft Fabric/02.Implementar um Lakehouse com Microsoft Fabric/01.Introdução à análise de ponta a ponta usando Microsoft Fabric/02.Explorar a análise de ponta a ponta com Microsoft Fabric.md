Análises escalonáveis podem ser complexas, fragmentadas e caras. Microsoft Fabric simplifica as soluções de análise fornecendo um único produto fácil de usar que integra várias ferramentas e serviços em uma única plataforma.

O Fabric é uma plataforma saaS ( _software como serviço_ ) unificada em que todos os dados são armazenados em um único formato aberto no OneLake. Todos os mecanismos de análise na plataforma podem acessar o OneLake, garantindo escalabilidade, custo-efetividade e acessibilidade de qualquer lugar com uma conexão com a Internet.

## OneLake

**O OneLake** é a arquitetura centralizada de armazenamento de dados do Fabric que permite a colaboração eliminando a necessidade de mover ou copiar dados entre sistemas. O OneLake unifica seus dados entre regiões e nuvens em um único lago lógico sem mover ou duplicar dados.

O OneLake é baseado em **Azure Data Lake Storage Gen2** (ADLS Gen2) e dá suporte a vários formatos, incluindo Delta, Parquet, CSV e JSON. Todos os mecanismos de computação no Fabric armazenam automaticamente seus dados no OneLake, tornando-os diretamente acessíveis sem a necessidade de movimentação ou duplicação. Para dados tabulares, os mecanismos analíticos no Fabric escrevem dados no formato delta-parquet e todos os mecanismos interagem com o formato sem interrupções.

![Diagrama de mecanismos de computação do Fabric, como Engenharia de Dados, Data Warehouse, Data Factory, Power BI e Real-Time Intelligence, todos acessando o mesmo armazenamento de dados do OneLake.](https://learn.microsoft.com/pt-br/training/wwl/introduction-end-analytics-use-microsoft-fabric/media/onelake-architecture.png)

**Shortcuts** são referências a arquivos ou locais de armazenamento no OneLake ou fontes de dados externas, como Azure Data Lake Storage, Amazon S3 ou Dataverse. Os atalhos permitem que você acesse os dados existentes sem copiá-los, garantindo a consistência dos dados e permitindo que o Fabric permaneça sincronizado com a origem.

Como todas as cargas de trabalho do Fabric armazenam dados no OneLake usando um formato aberto, recursos de IA como Copilot e agentes de dados podem acessar os mesmos dados controlados que seus relatórios e dashboards sem pipelines de preparação de dados separados. O trabalho que você faz para ingerir, preparar e controlar dados no Fabric é o que disponibiliza esses dados para cargas de trabalho de IA.

## Espaços de Trabalho

Em Microsoft Fabric, os workspaces servem como contêineres lógicos que ajudam você a organizar e gerenciar seus dados, relatórios e outros ativos. Eles fornecem uma separação clara de recursos, facilitando o controle do acesso e da manutenção da segurança.

Cada workspace tem seu próprio conjunto de permissões, garantindo que somente usuários autorizados possam exibir ou modificar seu conteúdo. Essa estrutura dá suporte à colaboração em equipe, mantendo um controle de acesso estrito para usuários de TI e de negócios.

Os workspaces permitem que você gerencie recursos de computação e integre-se ao Git para controle de versão. Você pode otimizar o desempenho e o custo definindo as configurações de computação, enquanto a integração do Git ajuda a controlar as alterações, colaborar no código e manter um histórico do seu trabalho.

## Administração e governança

O OneLake do Fabric é governado centralmente e aberto para colaboração. Os dados são protegidos e regidos em um só lugar, o que permite que os usuários encontrem e acessem facilmente os dados necessários. A administração do fabric é centralizada no **portal de administração**.

No portal de administração, você pode gerenciar grupos e permissões, configurar fontes de dados e gateways e monitorar o uso e o desempenho. Você também pode acessar as APIs de administrador do Fabric e os SDKs no portal de administração, que podem automatizar tarefas comuns e integrar o Fabric a outros sistemas.

O **catálogo do OneLake** ajuda você a analisar, monitorar e manter a governança de dados. Ele fornece diretrizes sobre rótulos de confidencialidade, metadados de item e status de atualização de dados, oferecendo insights sobre o status de governança e as ações de melhoria.
