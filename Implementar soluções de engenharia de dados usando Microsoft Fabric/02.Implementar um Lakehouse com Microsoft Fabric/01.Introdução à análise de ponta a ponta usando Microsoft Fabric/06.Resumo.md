As organizações precisam ingerir, preparar, governar e analisar dados em escala. Eles também precisam que os dados estejam prontos para cargas de trabalho de IA, como copilots, agentes e modelos de machine learning.

Microsoft Fabric fornece uma base unificada para ambos. Neste módulo, você explorou a arquitetura de armazenamento onelake do Fabric, as cargas de trabalho que atendem às diferentes necessidades de análise e como as equipes de dados colaboram dentro da plataforma.

Você também aprendeu como os recursos de IA se baseiam em dados bem controlados. Copilot fornece assistência inteligente em todas as cargas de trabalho, os agentes de dados permitem que os usuários consultem dados organizacionais em linguagem natural, e o Fabric IQ é uma carga de trabalho que ajuda os agentes a raciocinar entre domínios usando linguagem comercial consistente. Juntamente com o IQ do Foundry e o IQ de Trabalho, esses recursos posicionam o Fabric como uma plataforma de dados e uma plataforma de inteligência.
