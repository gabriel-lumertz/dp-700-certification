Um lakehouse no Microsoft Fabric utiliza o OneLake, um repositório de arquivos altamente escalonável baseado no Azure Data Lake Storage Gen2. O lakehouse inclui um metastore para objetos relacionais, como tabelas e exibições. Esses objetos usam o formato de tabela delta lake de software livre. Com o Delta Lake, você define esquemas de tabela e os consulta usando SQL.

Neste exercício, você executará as seguintes tarefas:

- Criar uma casa no lago
- Carregar arquivos
- Carregar dados de arquivo em tabelas
- Consultar tabelas lakehouse usando SQL
- Criar uma consulta visual
