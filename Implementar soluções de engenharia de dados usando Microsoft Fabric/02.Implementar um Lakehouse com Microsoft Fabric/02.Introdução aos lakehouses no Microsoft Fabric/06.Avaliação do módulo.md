2.Qual é a principal diferença entre o explorador de lakehouse e o ponto de extremidade de análise SQL?

O Lakehouse Explorer fornece acesso somente leitura, enquanto o endpoint de análises do SQL permite modificações de dados.

> [!Correct]
> O explorador de lakehouse permite interagir com tabelas, arquivos e pastas, enquanto o ponto de extremidade de análise SQL possibilita executar consultas T-SQL somente leitura em tabelas Delta.

Ambos fornecem funcionalidade idêntica com interfaces de usuário diferentes.
