Um **lakehouse** em Microsoft Fabric combina o armazenamento flexível de um data lake com as funcionalidades analíticas de um data warehouse. Um lakehouse usa mecanismos de computação do Apache Spark e do SQL para processar e analisar dados em escala e é criado na camada de armazenamento **do OneLake** .

Um lakehouse é uma plataforma unificada que combina:

- O armazenamento flexível e escalonável de um **data lake**
- A capacidade de consultar e analisar dados de uma **datawarehouse**

Imagine que sua organização depende de um data warehouse tradicional para análise de negócios. O armazém lida bem com dados transacionais estruturados, mas luta com o volume crescente de dados semiestruturados e não estruturados de fontes como logs de aplicativos, dispositivos IoT e feeds externos. Armazenar e processar esses diversos tipos de dados requer sistemas separados, criando silos de dados e esforços complexos de integração. Sua organização precisa de uma solução unificada que lide com dados estruturados e não estruturados, mantendo recursos analíticos fortes.

Neste módulo, você aprenderá como os lakehouses lidam com esses desafios. Você explora como criar um lakehouse, ingerir e transformar dados e consultar dados do Lakehouse usando SQL e Spark. Você também aprenderá como os dados do Lakehouse bem estruturados dão suporte às análises downstream e experiências com IA em toda a plataforma Microsoft Fabric.
