Neste módulo, você aprendeu a criar um lakehouse, trazer dados por meio de vários métodos de ingestão e consultar esses dados usando SQL e Spark. Você também explorou como a organização de dados lakehouse com esquemas claros e convenções de nomenclatura cria uma base que dá suporte não apenas a relatórios tradicionais por meio de Power BI, mas também experiências inteligentes alimentadas pelo Fabric IQ e Copilot.

Sem um lakehouse, as organizações geralmente mantêm sistemas separados para armazenamento de arquivos flexível e análise estruturada, levando a silos de dados, duplicação e integração complexa. Um lakehouse no Microsoft Fabric elimina essa divisão combinando ambas as funcionalidades em uma única plataforma, construída no OneLake.

Para obter mais informações, consulte a documentação de [Data Engineering do Microsoft Fabric](https://learn.microsoft.com/pt-br/fabric/data-engineering/).
