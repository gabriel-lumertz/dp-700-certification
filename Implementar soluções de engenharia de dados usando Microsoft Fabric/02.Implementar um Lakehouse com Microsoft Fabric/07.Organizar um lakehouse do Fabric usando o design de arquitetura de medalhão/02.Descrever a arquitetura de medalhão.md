Sistemas de origem (transações, exportações de CRM, logs) organizam dados para eficiência operacional, não análise. A **arquitetura medalhão** oferece uma maneira estruturada de reformular esses dados progressivamente, preservando os dados originais como uma fonte confiável, enquanto prepara esses dados camada por camada para relatórios e análises.

A arquitetura consiste em três camadas (bronze, prata e ouro), cada uma atendendo a um público diferente. Bronze é a zona de destino bruta para engenheiros de dados. Silver é um conjunto de dados limpo e integrado para analistas e cientistas de dados. O ouro é um modelo dimensional para usuários de negócios. Essa separação é o que torna o padrão poderoso: cada equipe obtém o que precisa sem que ninguém substitua do que os outros dependem.

## As três camadas

### Camada de bronze

A camada bronze é a camada de entrada para todos os dados, sejam estruturados, semiestruturados ou não estruturados. A camada bronze armazena dados em seu formato original, sem modificação. Manter os dados brutos aqui é intencional. Se uma transformação posterior der errado, você sempre poderá reprocessar a partir da camada bronze, em vez de voltar ao sistema de origem.

### Camada Prata

A camada de prata é onde você valida e refina seus dados. Atividades típicas incluem combinar e mesclar dados de várias fontes e impor regras de qualidade de dados, como remover nulos e eliminação de duplicação. O resultado é um conjunto de dados consistente e integrado que analistas e cientistas de dados podem usar diretamente e que alimenta a camada de ouro.

### Camada Ouro

A camada de ouro é onde você modela dados para uso comercial, normalmente como um **esquema de estrela** com fatos e dimensões. Depois que os dados atingem a camada de ouro, eles estão prontos para consumidores downstream: analistas executando relatórios, cientistas de dados criando modelos e usuários de negócios explorando painéis.

## Adaptar a arquitetura às suas necessidades

O padrão de três camadas é um ponto de partida, não uma regra estrita. Dependendo do caso de uso, você pode adicionar uma zona de destino antes do bronze para os dados que chegam em um formato específico ou uma camada específica do domínio além do ouro para as necessidades de uma equipe específica. Os nomes e o número de camadas são flexíveis. O que importa é que cada camada tem uma finalidade clara e um público claro.
