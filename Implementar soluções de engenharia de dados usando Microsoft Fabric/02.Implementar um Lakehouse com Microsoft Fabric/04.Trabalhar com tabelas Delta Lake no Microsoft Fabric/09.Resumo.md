O Delta Lake é uma tecnologia que adiciona semântica de banco de dados relacional ao Apache Spark. As tabelas em um Lakehouse do Microsoft Fabric são baseadas no Delta Lake, permitindo que você aproveite muitos recursos e técnicas avançadas por meio da API do Delta Lake.
