As tabelas em um lakehouse do Microsoft Fabric são baseadas no formato de tabela _Delta Lake_ do Linux Foundation, comumente usado no Apache Spark. O Delta Lake é uma camada de armazenamento de software livre para Spark que permite recursos de banco de dados relacionais para dados em lote e streaming. Usando o Delta Lake, você pode implementar uma arquitetura lakehouse para dar suporte à semântica de manipulação de dados baseada em SQL no Spark com suporte para transações e imposição de esquema. O resultado é um armazenamento de dados analítico que oferece muitas das vantagens de um sistema de banco de dados relacional com a flexibilidade do armazenamento de arquivos de dados em um data lake.

Embora você não precise trabalhar diretamente com APIs Delta Lake para usar tabelas em um Fabric lakehouse, uma compreensão da arquitetura do metastore Delta Lake e familiaridade com algumas das operações de tabelas Delta Lake mais especializadas amplia consideravelmente sua capacidade de criar soluções de análise avançada no Microsoft Fabric.
