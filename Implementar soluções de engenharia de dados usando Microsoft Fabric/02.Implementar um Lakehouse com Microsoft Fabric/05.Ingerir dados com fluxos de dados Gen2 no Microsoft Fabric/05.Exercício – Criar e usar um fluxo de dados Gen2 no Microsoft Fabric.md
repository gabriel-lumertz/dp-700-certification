Neste exercício, você usará um Fluxo de Dados Gen2 para carregar dados transformados em um lakehouse e adicionar um fluxo de dados a um pipeline.

> Você precisa de uma licença de avaliação do Microsoft Fabric com a versão prévia do Fabric habilitada no locatário. Confira [**Introdução ao Fabric**](https://learn.microsoft.com/pt-br/fabric/get-started/fabric-trial) para habilitar a licença de avaliação do Fabric.
